OSINT Briefing Uploader

개인 영상 제작 파이프라인의 유튜브 업로드 도구 · A personal YouTube upload tool

이 앱은 운영자 본인이 만든 롱폼 브리핑 영상을 운영자 본인의 유튜브 채널에 비공개로 올리는 내부 도구입니다. 일반 사용자에게 제공되는 서비스가 아니며, 다른 사람의 계정이나 채널에 접근하지 않습니다.

This app is an internal tool that uploads long-form briefing videos produced by the operator to the operator's own YouTube channel as private videos. It is not offered to the public and does not access anyone else's account or channel.

하는 일 · What it does

  • 완성 영상 파일, 제목·설명, 자막(SRT)을 YouTube Data API로 업로드합니다. Uploads the finished video, its title/description and captions via the YouTube Data API.
  • 업로드 공개 범위는 항상 비공개입니다. 공개 전환은 운영자가 YouTube Studio에서 직접 합니다. Videos are always uploaded as private; publishing is done manually in YouTube Studio.
  • 요청 권한: youtube.upload(영상 업로드), youtube.force-ssl(자막 업로드). Scopes requested: youtube.upload, youtube.force-ssl.
