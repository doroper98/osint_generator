개인정보처리방침 · Privacy Policy

OSINT Briefing Uploader · 시행일 Effective 2026-11-03

1. 대상 · Scope

OSINT Briefing Uploader(이하 "앱")는 운영자 1인이 자기 유튜브 채널에 자기 영상을 올리기 위해 쓰는 내부 도구입니다. The app is an internal tool used by a single operator to upload their own videos to their own YouTube channel.

2. 접근하는 Google 사용자 데이터 · Google user data accessed

  • https://www.googleapis.com/auth/youtube.upload — 영상 업로드와 업로드 결과(영상 ID) 수신. Upload videos and receive the resulting video ID.
  • https://www.googleapis.com/auth/youtube.force-ssl — 업로드한 영상에 자막 추가. Add captions to uploaded videos.

앱은 채널의 다른 영상, 댓글, 시청 기록, 구독자 정보, 연락처를 읽지 않습니다. The app does not read other videos, comments, watch history, subscriber data or contacts.

3. 사용 목적 · How the data is used

받은 권한은 운영자가 만든 영상과 자막을 비공개로 올리는 데만 씁니다. 광고, 분석, 프로파일링, 판매에 쓰지 않습니다. Access is used only to upload the operator's videos and captions as private videos. It is never used for advertising, analytics, profiling or sale.

4. 저장 · Storage

  • OAuth 리프레시 토큰은 운영자의 실행 환경 비밀 변수에만 저장합니다. 소스 코드, 로그, 커밋에 남기지 않습니다. The OAuth refresh token is stored only as a secret in the operator's execution environment, never in source code, logs or commits.
  • 업로드 결과(영상 ID, URL, 업로드 시각, 공개 범위)는 운영자의 프로젝트 기록 파일에 남습니다. Upload results (video ID, URL, time, privacy status) are kept in the operator's project records.

5. 공유 · Sharing

Google 사용자 데이터를 제3자에게 제공하거나 판매하지 않습니다. 데이터는 YouTube API를 호출할 때 Google에만 전송됩니다. Google user data is not shared with or sold to any third party. Data is sent only to Google when calling the YouTube API.

6. 권한 철회와 삭제 · Revocation and deletion

언제든 Google 계정 권한 페이지에서 앱의 접근 권한을 철회할 수 있습니다. 철회하면 앱은 더 이상 업로드할 수 없습니다. 운영자는 철회 시 저장된 토큰을 삭제합니다. You can revoke the app's access at any time on the Google security settings page. After revocation the app can no longer upload, and the stored token is deleted.

7. Google 정책 · Google policies

이 앱은 YouTube API Services를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다. This app uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy also apply. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
