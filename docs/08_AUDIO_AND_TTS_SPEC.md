## 2.5 숫자·단위 발음 규칙 (v0.48.1 확정 — 구현: `orchestrator/tts_pronounce.py`)

한국어 숫자 낭독은 **연음(liaison)·경음화(tensification)가 한 호흡 안에서만 일어난다.**
공백 하나가 발음을 기계음으로 만든다.

| 규칙 | 옳음 | 틀림 (AI 슬롭) | 근거 |
|---|---|---|---|
| 한 수의 음절은 전부 붙인다 | `백육십팔` [뱅뉵씹팔] | `백 육십 팔` [배규십팔] | TTS-AP-058 |
| 숫자와 단위어도 붙인다 | `백육십팔딸러` [뱅뉵씹팔딸러] | `백육십팔 딸러` […팔 / 딸러] | TTS-AP-065 |
| 천단위 콤마는 하나의 수로 | `1,395,000원`→`백삼십구만오천원` | `일,삼백구십오,영 원` | TTS-AP-064 |
| 소수점은 '쩜' 무공백 | `168.49`→`백육십팔쩜사구` | `백육십팔 점 사구` | TTS-AP-059 |
| 외래어 단위는 경음 사전 | 달러→딸러, 유가→유까 | 사전 미적용 낭독 | TTS-AP-054 |
| 고유어 수사 단위 | 9곳→아홉 곳, 두 배 | 구 곳 | — |

- 기존 "숫자와 단위어 사이 공백 1칸" 방침(v0.43.4)은 **폐기** — 실청취에서
  [백육십팔 / 딸러]로 끊겨 AI 티가 났다 (사용자 피드백 2026-07-12).
- 8자리(9,999만) 초과 수는 변환하지 않고 남긴다 → §4-a 린트가 `숫자잔재`로 잡는다.

## 2.6 문장 종결·절단 규칙 (v0.48.1 확정 — 구현: `bundle_to_video.py`)

**말하다 마는 음성은 최악의 슬롭이다.** 문장은 반드시 끝맺거나, 아예 싣지 않는다.

1. **중간 절단 금지**: 자막·음성 텍스트를 글자 수로 중간에서 자르지 않는다(`clip()`의
   `…` 금지). 절단은 **문장 경계에서만** — `clip_cue()` 사용. 첫 문장부터 예산을
   넘으면 **길어도 통째로** 싣는다(자막 박스가 2줄로 감싼다).
2. **원문 절단 표식(`…`/`...`) 되감기**: 원문이 "…거래로 …"처럼 잘려 왔으면 마지막
   완결 문장까지 되감는다(`settle_ellipsis`). 완결 문장이 없으면 자막은 **생략**,
   음성은 **침묵** — 억지 문장·반토막 낭독보다 낫다. (TTS-AP-066)
3. **경어체 활용**:
   - 이미 경어체(`…니다/니까/세요` 등)인 문장에 `to_polite` 재적용 금지 —
     "팔았습니다"→"팔았습니습니다" 사고. (TTS-AP-067)
   - 받침 ㄴ+`다` 현재형은 ㄴ→ㅂ 교체: 둔다→**둡니다**(둔습니다 아님), 온다→옵니다.
   - `는다`는 `습니다`로: 먹는다→먹습니다, 짓는다→짓습니다.

## 3. TTS Pronunciation QA (필수)

흐름:
1. 원문 텍스트.
2. `pronunciation_ko.yaml` 적용 → normalized text.
3. TTS 생성 → wav.
4. ASR 재인식.
5. 원문 / 발음 사전 정답과 비교.
6. 실패 segment 자동 재생성.

본 단계 없이 최종 음성을 확정할 수 없다 (GOAL G4-9).

## 4. AI 티 안티패턴

본 시스템은 [docs/ANTIPATTERNS/TTS_ANTIPATTERNS.md](ANTIPATTERNS/TTS_ANTIPATTERNS.md)에 정리된 항목을 모두 회피한다. Worker는 다음을 자동 검사한다.

- 숫자/단위/날짜 정규화 적용 여부
- 약어 발음 사전 일치
- 기호(/, -, →, :, ~, (), [], ※, ▲, ▼) 제거 또는 변환
- 문어체 → 구어체 변환
- URL / 파일 경로 음성 미낭독 (자막으로 우회)

### 4-a. 빌드 시점 자동 린트 게이트 (v0.48.1 — `bundle_to_video.lint_cues`)

**"한두 건만 들려도 영상 전체가 AI 티가 나는"** 클래스는 사후 검수가 아니라
빌드 시점에 잡는다. `convert()` 가 최종 cue(자막 text + 음성 tts) 전수를 훑어
경고를 출력한다 — 경고가 나오면 그 영상은 확정하지 않는다.

| 카테고리 | 잡는 것 | 예 |
|---|---|---|
| `절단(자막)` | 자막이 `…`/`...`로 끝남 | "SK하이닉스는 이번 거래로 …" |
| `미완(자막/음성)` | 종결부호 없이 조사·연결어미로 끝남 | "…이번 거래로" (말하다 맒) |
| `숫자잔재(음성)` | 음성에 아라비아 숫자 잔존 | "168달러에" |
| `콤마잔재(음성)` | 한글 수사 사이 콤마 | "일,삼백구십오,영 원" |
| `이중경어(음성)` | `니습니다`/`다습니다` | "팔았습니습니다" |
| `ㄴ다오활용(음성)` | 받침 ㄴ+습니다 (예외: 신습니다) | "무게를 둔습니다" |

회귀 테스트: `tests/test_cue_copy.py` + `tests/test_tts_pronounce.py` (순수 함수,
디스크 불필요). 새 슬롭 클래스를 발견하면 ① AP 번호 append ② 린트 카테고리 추가
③ 테스트 케이스 추가 — 세 가지가 한 세트다 (C6 구조적 조치).

## 5. 음성용 대본 vs 자막용 대본 분리

- **음성용 대본**: 발음형으로 정규화된 텍스트 (`narration_segments.json`).
- **자막용 대본**: 화면에 보이는 표기 (`scene_manifest`의 caption).
- 같은 문장이라도 둘은 다를 수 있다. 예: 자막 "16시", 음성 "오후 네 시".

## 6. BGM

- **생성형 음악 사용**. 유료 라이브러리 사용 안 함.
- 테마: 공포 / 긴장 / 격화 / 개전 / 협상 / 정보전 (chapter별 선택).
- 형식: 20–30초 루프.
- 악기: 느린 피아노, 첼로, 드론, 북소리.
- 매우 낮은 볼륨. 내레이션 방해 금지.

## 7. 믹싱

- 룸톤(미세 노이즈) 일부 유지 → 너무 매끈하지 않게.
- 치찰음 dampening.
- 문장 끝 잔향 살짝 유지.
- 압축 과도 사용 금지 (라디오 광고 톤 회피).

## 8. 호흡 / 리듬

- 긴 문장 강제 분할.
- 매 쉼표 동일 멈춤 회피 (Antipattern TTS-AP-08 참조).
- 문장 끝 톤이 매번 같지 않도록.
