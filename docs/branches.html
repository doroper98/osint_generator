GitHub Personal Access Token

본 저장소가 Private 이므로 브랜치/커밋/PR 데이터를 받으려면 토큰이 필요합니다.
토큰은 이 브라우저 localStorage 에만 저장됩니다. 저장소에는 절대 들어가지 않습니다.

발급 방법: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Resource owner 본인 → Repository access = osint_generator → Repository permissions: Contents: Read-only, Metadata: Read-only, Pull requests: Read-only.
