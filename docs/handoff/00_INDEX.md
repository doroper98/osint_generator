> 기준 산출물: 채팅에서 직접 만든 지도 중심 다큐 영상 3편 (v1 → v2 → v3). **v3가 정본(canonical)이다.**

## 0. 이 문서 묶음의 목적

1. 채팅 세션에서 만든 영상 제작 파이프라인(지도 엔진·카메라·인물 뱃지·패널·자막·오디오·원고 검사)을 **재현 가능한 수준으로** 기록한다.
2. 사용자(YK)가 준 **모든 피드백과 그 해결 방식**을 원문 그대로 남긴다. 같은 실수를 반복하지 않기 위해서다.
3. 기존 osint_generator에서 **버릴 것 / 고쳐 쓸 것 / 그대로 계승할 것**을 명확히 가른다.
4. Claude Code가 단계별로 실행할 수 있는 **구현 계획과 합격 기준**을 준다.

사용자가 직접 한 말(이 개편의 헌법):

> "나는 이전 저장소에 있던 영상 생성을 위한 기준들이 마음에 들지 않는거야."
> "osint generator 가 기존에 만들었던 부분들을 최대한 버릴 부분을 발라내고 너가 만든 영상이나 파이프라인, 워크플로우를 받아들일 수 있도록 하는게 목표야."
> "12막 기준으로 영상을 우겨넣지 말것. 이부분이 탈피하고 싶은 가장 큰 부분임."
> "나는 영상미 만큼은 너가 만든게 훨씬 우수하다고 생각해."

## 1. Claude Code에게 — 작업 방식 지시

1. **읽는 순서**: `00` → `01` → **`15`(관성 방지 원칙)** → `02` → `16` → `13` 을 먼저 전부 읽는다. 그다음 구현 단계마다 해당 영역 문서(`03`~`12`, `14`, `17`, `18`)를 다시 연다.
2. **`reference_code/v3_hormuz_korea/`는 동작하는 프로토타입이다.** 설계를 새로 발명하지 말고, 이 코드를 모듈로 분해·정리하는 것부터 시작한다. 수치(두께, 알파, 타이밍, 색)는 사용자가 이미 합격 판정을 내린 값이다. 근거 없이 바꾸지 않는다.
3. **HyperFrames/Remotion 기반 브리핑 렌더러(`hyperframes/briefing/*`, `remotion/*`)는 새 영상 경로에서 쓰지 않는다.** 보관(archive)만 한다. 이유는 `02` §4.
4. **사실 정확성·권리·검증 원칙(기존 GOAL G4, CLAUDE C9)은 계승한다.** 영상미를 위해 이 원칙을 깨지 않는다. 기존 저장소 규칙 중 사용자가 불만을 가진 것은 "영상 생성 기준"(구성·타이포·화면 문법)이지 거버넌스가 아니다.
5. **사용자 피드백은 `01`의 원문과 해결 방식을 기준으로 판단한다.** 새 결정이 필요하면 추측하지 말고 사용자에게 묻는다.
6. 각 단계는 **프리뷰 컨택트 시트(24프레임 내외)로 육안 검수 → 전체 렌더** 순서를 지킨다. (`11` §5)
7. 채팅 샌드박스 제약(도구 호출 시간 제한, 백그라운드 프로세스 종료, 1 vCPU) 때문에 생긴 우회책(청크 렌더, 접두부 재인코딩 등)은 로컬에서는 필요 없을 수 있다. `11`에 구분해 적었다.

## 4. 핵심 원칙 요약 (사용자 합의 완료)

1. **지도는 배경이 아니라 무대다.** 한 좌표계를 이어 쓰며 카메라가 이동한다. 장면마다 새 지도를 띄우지 않는다.
2. **고정 막 구조 금지.** 주제에 맞게 장면 수·길이·구성을 자유롭게 정한다. 영상 길이 제한 없음.
3. **카메라는 한 장면에 한 번만 움직인다.** 먼 거리는 0.5초 암전 컷. 줌이 튀어 오르는 연출 금지.
4. **확대하면 정보가 늘어난다.** 줌 단계별로 행정구역 경계·도시·해역 이름이 나타난다. 국경선만 있는 휑한 화면 금지.
5. **화면 모서리에는 날짜만.** 브랜드명, 섹션 번호(01/12), 섹션 제목 금지.
6. **도장(미확인 등) 금지.**
7. **인물·국기·휘장은 원형 뱃지로 명확히.** 국가=국기, 기관=실제 휘장, 인물=흑백 컷아웃+국기.
8. **관계선은 천천히, 하나씩, 정돈되게.** 내레이션 단어에 맞춰 상태가 바뀐다.
9. **AI 상투 문구 금지** (`03` §2 목록, 정규식 린트로 강제).
10. **발음은 저장소 TTS 안티패턴 문서를 따른다.** 자막용 텍스트와 발음용 텍스트를 분리한다.
11. **폰트는 agents_reviewer 르포 폰트.** IBM Plex Sans KR / Noto Serif KR / GmarketSans / IBM Plex Mono.
12. **배경음악은 들리게.** 내레이션 중에도 묻히지 않는 수준(v3 값).
13. **사실·권리·검증 위에서만 영상미를 추구한다.** 모든 수치는 출처가 있고, 추정은 "추정"으로 표시한다. 논쟁적 사안은 양쪽 논거를 출처와 함께 제시한다.
14. **해상도는 트라이얼 기간 480p.** 최종 파이프라인은 해상도 독립적으로 설계한다(`09` §2 스케일 규칙).
16. **비네팅 없음.** 화면 가장자리를 어둡게 하는 효과를 쓰지 않는다(라운드 6).
17. **엔딩 카드는 유지하되 절제된 에디토리얼 디자인.** 작은 글씨, 2단 구성, 섹션별 정리(`09` §6.2).
18. **사진·영상은 사실 자료만.** 공개 라이선스 실사 자료, 자료사진은 연월 표기, AI 생성 금지(`14`).
19. **미디어 비트는 표준 구성.** 영상·사진·컷아웃·기사 클리핑을 러닝타임 40~60초당 1개씩 섞어 넣는다(`14` §10).
15. **목소리는 교체 가능한 부품.** 사용자의 ElevenLabs 커스텀 목소리로 바꿀 수 있어야 하고, 모든 연출은 문장 기준으로 자동 재배치된다.

## 5. 용어집

| 용어 | 뜻 |
|---|---|
| 장면(scene) | 원고의 의미 단위. v3는 11개(open, route, war, ask, timeline, cost, review, past, debate, decision, now). 개수는 주제마다 다르다. |
| 숏(shot) | 카메라가 한 위치/프레이밍에 머무는 구간. 한 장면에 보통 1개, 많아야 2개. |
| 문장 앵커(sentence anchor) | 모든 연출 이벤트의 시각을 "문장 id + 오프셋초"로 지정하는 방식. `S('war_2', 0.3)` = war 장면 3번째 문장 시작 0.3초 뒤. 음성이 바뀌어도 연출이 자동으로 따라온다. |
| 단어 앵커(word anchor) | 문장 안 특정 단어가 발음되는 추정 시각. `at_word(sid, '독일')`. v3는 글자 비율로 추정, ElevenLabs 전환 시 글자 단위 정렬값으로 대체. |
| 티어(tier) | 해상도가 다른 지형 베이스 래스터 묶음. v3: W(광역, 24ppd), G(걸프, 96ppd), K(한반도, 96ppd). |
| ppd | pixels per degree (경도 1도당 픽셀). 메르카토르 '도 단위' 좌표계에서의 해상도. |
| 메르카토르 도 단위 | u = 경도, v = degrees(ln(tan(π/4 + 위도/2))). 두 축 모두 '도' 단위라 ppd 하나로 스케일이 정해진다. |
| LOD | level of detail. 줌(w, 화면 가로 경도폭)에 따라 표시 요소를 바꾸는 규칙. |
| 암전 컷(dip) | 1초 동안 검게 가렸다 밝히며 그 중간에 카메라를 순간 이동시키는 전환. |
| 뱃지(badge) | 원형 인물/국기/휘장 표기 컴포넌트. |
| 패널(panel) | 지도를 어둡게 덮고 그 위에 그리는 정보 화면(관계도, 연표, 찬반 등). |
| 카드(card) | 지도 위 우측 상단에 슬라이드 인하는 작은 정보 상자(수치, 인용). |
| RESERVED | 프레임마다 마커·뱃지가 차지한 화면 영역 목록. 도시 라벨이 이 영역과 겹치지 않게 한다. |
| 린트(lint) | 원고 자동 검사. 금지 문구, 발음 텍스트의 숫자·기호, 강조어 누락을 잡는다. |
