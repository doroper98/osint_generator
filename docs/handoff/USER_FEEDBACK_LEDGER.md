# 사용자 의견 원장 — 기록하고, 재발을 막는다

사용자 지시(2026-10-11): **"내가 코멘트 한 사항들은 모두 기록되고 재발이 되면 안돼."**

이 문서는 사용자가 영상·화면을 보고 준 의견을 한 줄도 빠짐없이 적는 원장이다.
각 의견은 **재발 방지 장치(검사·테스트·규칙 키)** 와 짝을 이룬다. 장치가 없는 의견은 "미보호"로 남고, 미보호가 있으면 다음 영상의 게이트를 통과하지 못하게 한다(D-0200 — 기계 판독 원장 `rules/user_feedback.yaml` 과 검사로 구현).

규칙:
1. 의견을 받으면 **그 자리에서** 원문 그대로 한 줄을 붙인다(감독 또는 구현 세션). 고친 뒤가 아니다.
2. 과거 줄은 고치지 않는다(append-only). 상태 변화는 새 줄 또는 상태 칸 갱신 기록으로.
3. 장치 칸에는 **실제로 실패를 내는 것**(checks id·테스트 경로·규칙 키)만 적는다. "주의하겠다" 는 장치가 아니다.
4. 같은 의견이 다시 나오면 그것은 **재발**이다. 재발 줄에 원래 번호를 적고, 원인(장치가 왜 못 잡았나)을 AP 항목으로 남긴다.
5. 장치는 저장소 전체 영상 경로에 걸린다(한 트랙·한 도구에만 걸린 장치 = 미보호, UF-02 교훈).
