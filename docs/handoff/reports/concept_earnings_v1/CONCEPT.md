# 실적 발표 템플릿 — 구상안 v1 (삼성전자 2026년 3분기 편, 인텔 편 차이 포함)

작성: 감독(Fable) 2026-10-30 · 근거: D-0278(다섯 막)·D-0302(사용자 결정)·D-0308(차트 어휘)·D-0309(다차원·소화 가능)
상태: **사용자 검토용 구상**. 그림 4장은 개념 와이어프레임(코드로 그린 목업)이며 실제 엔진 렌더가 아니다 — 요소 승인은 실제 렌더 스케치로 따로 받는다(20 §4.1).

## 1. 한 줄 개념
"사상 최대 실적을 낸 날, 주가는 내렸다" — 예상·실제·부문·가이던스·주가·지경학을 **차트 하나의 세계** 위에서 층을 하나씩 켜며 따라간다. 화면 글자는 자막을 되풀이하지 않고, 구석 카드는 없다.

## 2. 지켜지는 원칙
- 차트 세계 하나: 시간축·축척은 영상 내내 고정, 카메라는 날짜 이동만. 사진 배경 + 차트 아일랜드(화면 63 %).
- 층은 설명 문장에서만 켜진다. 동시 가시 계열 ≤4, 레인 ≤3, 층 ≤5, 새 층 뒤 4초.
- 수치는 레코드에서만: 실적 = 삼성 IR 발표 자료(별첨 2), 컨센서스 = 보도가 전한 집계치(기관 귀속), 주가 = Yahoo 일별 종가(비공개 시청), 시간외 = 보도 인용.
- 차이(%)·교차 판정은 코드 계산. 산문 주석 없음. 투자 권유 없음, 엔딩에 투자 고지. 타이틀 부제·엔딩에 "실적 발표 템플릿" 표시.

## 4. 인텔 편 차이(같은 템플릿)
- act1: EPS 0.52 vs 예상 0.41(bullet, +27 %) · 매출 16.5 vs 16.5(일치).
- act2: 부문 쌓임에 **음수**(파운드리 영업손실 -1.9) 포함, 0 기준선 뚜렷. DCAI > CCG 교차 라벨(코드 판정).
- act3: 수치 가이던스 — 4분기 매출 **속빈 범위 캡슐 15~16** + 컨센서스 속빈 점 17.1(겹치지 않음이 한눈에), EPS 0.25 vs 0.43.
- act4: 시간외 -20 %대(보도 인용, 창 "시간외") + 10/30 종가(장 마감 뒤 채움).
- act5: 미 정부 9.9 % 지분·엔비디아 50억 달러(협력 실선), 이스라엘 Fab 28 사고 핀, PC 수요·메모리 부족(삼성 편과 같은 고리 컷).
