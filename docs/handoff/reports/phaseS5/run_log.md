## 2. 전황 화살표 부드럽게(D150 #8)

**원인**: `sketch/campaign/arrows.py` 가 자란 길이를 `np.searchsorted(L, L[-1]·prog)` 로 스플라인 꼭짓점 단위(정수)로 잘랐습니다. 끝이 꼭짓점 사이에서 멈췄다가 꼭짓점 하나씩 건너뛰었습니다.

**수정**: 끝점을 호 길이 보간(꼭짓점 i·i+1 사이 분수 위치 e)으로 둡니다. 띠 폭 매개 u = i / e, 라벨 자리 = 분수 위치 (e + 1) / 2 입니다.
- 원본은 prog = 1 에서도 `searchsorted`(왼쪽) 때문에 마지막 스플라인 꼭짓점을 그리지 않았습니다. 같은 자리에서 경로를 자르므로(`drawn_path`) 완성된 화살표는 원본과 **같은 다각형**입니다.
- D-0154 가 예로 든 "스플라인 표본 수를 화면 길이 기준으로" 는 하지 않았습니다. 표본을 늘리면 완성된 화살표 픽셀이 바뀌어, 같은 지침의 "완성 컷 0.000 %" 와 충돌합니다. 끝점 보간만으로 끊김이 사라져 필요가 없었습니다(아래 실측).
- 새 규칙 키 `sketch.campaign.arrow.max_step_px`(0.5)는 테스트 상한입니다. 성장 끝점의 프레임 간 이동이 호 길이 증가분을 넘는 허용 폭입니다.

**실측**: 우라누스 화살표 6개, 24fps, 각 화살표 끝 시각의 카메라에 고정해 성장만 분리했습니다.
