# 14. 사진 · 영상 · 컷아웃 삽입

사용자 요청(라운드 6 원문):
> 혹시 agent reveiwer 에 보면 본문에 사진을 넣는 기능이 있는데, 우리 영상에도 키가 되는 사진을 넣을 수 있을까? 이를테면 분쟁 이야기가 나오면 분쟁 사진을 넣는다던지, 회담을 가졌다면 회담을 가졌다는 사진을 넣는다던지, 무기에 대한 이야기가 나오면 지도상에 작게 해당 무기 사진을 넣는다던지, 사진이나 영상이 좀 들어가면 좋을 거 같은데 말이야.. 영상은 어떻게 넣을 수 있지?

v3 최종본에 네 가지 형태(사진·영상·컷아웃·기사 클리핑)를 적용했다. 라운드 7에서 사용자가 이 형태를 **모든 영상의 표준 구성**으로 넣으라고 지시했다(§10).

라운드 7 원문:
> unclassified 영상과, 기사에 포함 된 경계 근무 사진, p-8 사진 잘 봤어. 잘 들어갔네. 그런 형태로 기사와 영상이 중간중간 들어가는 형태로 만들어지는 부분도 추가 해. 참조 코드: `v3_hormuz_korea/media3.py`(수집·가공), `render3.py`(`draw_photo`, `draw_clip`, `draw_cutout`, `media_frame`, `media_caption`, `media_tag`), `media_registry.json`

### 2.2 금지
- **사실을 보여 주는 AI 생성 이미지·영상 금지**(저장소 G4-10: 실사 입력 없는 사실 생성 금지). 무기·회담·피해 현장을 생성 이미지로 대신하지 않는다.
- 사상자·시신이 식별되는 영상/사진 금지(유튜브 정책·시청 연령 제한 위험). v3 공습 영상은 사람이 보이지 않는 1.5~6.5초 구간만 잘라 썼다(13초 이후 소형 선박 타격 구간은 제외).
- 출처 불명 이미지(SNS 퍼온 사진 등) 금지.

### 2.3 저널리즘 표기 규칙
- 해당 사건 당일 자료가 아니면 반드시 **"자료사진 · 연월"** 표기(v3: "자료사진 · 2023. 05").
- 무기·장비 사진이 해당 사건의 그 개체가 아니면 **기종 예시**임을 명시(v3: "해상초계기 P-8A · 자료사진").
- 모든 사진·영상 아래에 **캡션 + 출처 줄**(촬영일 · 저작자 · 라이선스). CC BY 요건을 화면에서 즉시 충족한다.
- 엔딩 카드 '사진 · 영상' 섹션과 유튜브 설명란에도 기록.

## 3. 가공 (`media3.py`)

```python
# 사진: 16:10 크롭 + 톤 맞춤
im = 표준 썸네일 폭(1280) 다운로드 → 커버 크롭 720×450
im = ImageEnhance.Color(im).enhance(0.82)       # 채도 18% 낮춤(어두운 지도 톤과 조화)
im = ImageEnhance.Contrast(im).enhance(1.06)

# 컷아웃(무기·장비): 사물용 배경 제거
sess = rembg.new_session('isnet-general-use')   # 인물은 u2net_human_seg, 사물은 isnet-general-use
cut = remove(img, session=sess) → 알파 bbox 크롭 → 폭 360 리사이즈 → PNG

# 영상: 구간 추출 → 프레임 배열
ffmpeg -ss 1.5 -t 5.0 -i strikes.webm -vf "scale=480:270,fps=24" -f rawvideo -pix_fmt rgb24 out.rgb
np.save('strikes_480.npy', frames.reshape(-1,270,480,3))   # 120프레임, 46MB → 렌더 시 mmap_mode='r'
```
- 원본 확인용으로 영상 전체에서 12장 썸네일 시트를 만들어 구간을 사람이 고른다(v3: 1.0~7.2초 구간의 폭발 장면 선택).
- 긴 클립(10초 이상, 여러 개)은 npy 대신 **ffmpeg 서브프로세스 스트리밍**을 권장: 클립별로 `ffmpeg -ss {in + (청크시작−t0)} -i … -f rawvideo -` 파이프를 열고 프레임 순서대로 읽는다(청크 렌더 시 시작 오프셋 보정 필요).
- 위키미디어 webm 원본 다운로드가 "File ended prematurely" 경고를 내도 사용 구간이 온전하면 무방. 불안하면 재다운로드 또는 트랜스코드본 사용.

## 5. 배치 규칙
1. 장면당 미디어 1개 이하. 지도가 주인공이다.
2. 사진·영상은 **해당 문장이 말하는 대상**일 때만(단어 앵커로 등장).
3. 표시 시간: 사진 4~8초, 영상 3~6초, 컷아웃은 해당 문장 동안.
4. 우상단 카드, 우상단 날짜, 하단 자막(y ≥ 410), 중요한 마커를 가리지 않는다.
5. 클립이 패널을 덮을 때는 패널의 핵심 요소가 이미 보인 뒤(또는 클립이 끝난 뒤 보이도록 타이밍 조정).
6. 사진은 채도를 낮춰 지도 톤과 맞추되, 원본 의미를 바꾸는 보정(합성·삭제)은 금지.

## 9. 기사 클리핑 카드 (`article`, 라운드 7)

매체 보도를 인용하는 문장("~는 ~라고 보도했습니다")에서 신문 스크랩처럼 보이는 카드를 우상단 카드 자리에 띄운다. **기사 화면 캡처는 쓰지 않는다**(기사 본문·레이아웃 저작권). 우리 타이포로 매체명·날짜·헤드라인 번역(요지)만 조판한다.

```python
위치: 우상단 카드 자리 x = W − 300 − 24 (+30px 슬라이드), y = 68, 폭 300 (같은 시각에 일반 카드와 동시 표시 금지)
종이: 둥근 사각형 r3, 색 (0.95, 0.935, 0.905), 그림자 2겹(6px 0.12, 3px 0.2)
1행: 매체명 Noto Serif Bold 12.5 잉크색(0.1,0.105,0.12) / 오른쪽 날짜 IBM Plex Mono 8.5 회색
구분선: 0.8px 잉크 0.35
헤드라인: Noto Serif Bold 13.5, 폭 268 줄바꿈, 줄 간격 20
형광펜: 헤드라인 속 핵심 구절(hl)에 호박색(1.0,0.8,0.3, 0.55) 사각형이 0.8초 후 0.7초 동안 왼쪽→오른쪽으로 그어짐
부제: IBM Plex Sans KR 9.5 회색, 줄 간격 14 (기사 속 발언·맥락 요지)
하단: 'ARTICLE' Mono 7.5 (좌) / '헤드라인 번역 · 원문 영어' Sans 7.8 (우)
페이드 0.45초
```
규칙:
- 헤드라인은 **번역 또는 요지**로 짧게(원문 인용은 15단어 미만). 번역임을 하단에 표기.
- 매체·날짜는 원고 `sources` 필드와 일치해야 한다.
- 화면에 매체 로고(상표)를 쓰지 않는다. 매체명은 텍스트로.

## 10. 미디어 비트 — 모든 영상의 표준 구성 (라운드 7)

### 10.1 밀도
- 러닝타임 **40~60초당 1개**. v3: 292초에 7개(영상 2, 사진 2, 컷아웃 1, 기사 2) → 약 42초당 1개.
- 장면당 1개 이하(기사 카드는 일반 카드 자리를 대체하므로 예외적으로 사진/영상과 같은 장면 허용).
- 연속 두 장면에 같은 형태를 반복하지 않는다(영상→사진→기사→컷아웃처럼 섞기).

### 10.2 트리거 → 형태
| 문장 내용 | 형태 | 예 |

### 10.3 작업 흐름 (Claude Code가 구현할 단계)
1. **원고 단계**: 문장에 `media` 필드(선택) — `{kind, query 또는 asset_id, at: 단어, dur}`. 비어 있으면 §10.2 규칙으로 후보 제안.
2. **수집**: 위키미디어/DVIDS 검색 → 라이선스·제한 필터(`07` §3.2) → 후보 목록.
3. **검수 시트**: 영상은 12장 썸네일(시각 표시), 사진은 크롭 미리보기 → 사람이 구간·사진 선택. (v3: 유조선 사진 후보가 풍력발전 단지 위주라 **탈락** — 관련성 없는 자료는 넣지 않는다.)
4. **가공**: §3.
5. **배치**: 예약 영역(카드·날짜·자막·핵심 마커·뱃지)을 피해 자동 배치. 기본값 — 지도 위 영상은 좌측(x=40), 패널 위 영상은 중앙, 사진은 카드가 없을 때 우하단/패널 빈 공간, 기사는 카드 자리.
6. **크레딧**: 레지스트리에서 화면 캡션·엔딩 카드·설명란 자동 생성.
7. **자료 없음 → 넣지 않음.** 생성 이미지로 대체하지 않는다.

### 10.4 위키미디어 다운로드 운영 교훈 (라운드 7에서 실제 발생)
- 짧은 시간에 API·업로드 서버 요청이 몰리면 **HTTP 429가 수 분간 지속**된다. 해결: 60~90초 대기 후 재시도, 요청 사이 15초 간격, 원본 URL 직접 다운로드, 비표준 폭 썸네일 금지.
- 원본 URL에 `?utm_...` 쿼리가 붙어 있으면 썸네일 경로 추정 시 제거해야 한다(400 오류).
- extmetadata `Artist`가 비어 라이선스 템플릿 문자열이 섞여 들어오는 경우가 있다(v3 이라크 사진) → 저작자 필드는 정제 후 비어 있으면 라이선스 근거(예: "U.S. Government (PD-USGov)")로 기록.
