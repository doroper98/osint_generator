# V2 게이트 결정 — 참값은 음향 발화 시작(A) + 문장 안 어절은 간격 일치 검사. edge 는 참고 표 (DECISIONS D159)

## 1. Fable 검증(R-0195 §2 를 독립 재현)
| 측정 | Opus(R-0195) | Fable |
|---|---|---|
| `gate_rows_prototype.json` 851어절 재계산 | raw 중앙값 109·p90 267, 음수 0 / 쉼 뒤 197어절 \|오차\| 중앙값 21·p90 51 / 문장 안 654어절 +102·p90 138 | **같은 값**(109/267/0 · 21/51 · 102/138/p10 79) |
| 호르무즈 45문장, 이 컨테이너 edge 캐시(MMS 없이 음향만) | — | edge 첫 글자 시각 0.100~0.153초(고정값처럼). **문장 시작**: 원본 발화 시작 − edge 첫 글자 = 중앙값 **+285ms**(p10 256·p90 320). **쉼(≥150ms, \|a\|<0.012) 뒤 40어절**: 발화 시작 − edge = 중앙값 **+254ms**(p10 114·p90 324), 음수 4 |

결론: edge `WordBoundary` 는 절대 시각이 아니다. (a) 문장 시작을 0.1초에 고정 (b) 쉼 앞 경계를 쉼 시작에 둔다 (c) 문장 안에서도 약 100ms 이르다. 어떤 정렬기도 edge 를 참값으로 두면 통과할 수 없다(D 기각). 상수 보정(C)은 보정값을 같은 측정에서 고르는 순환이라 기각.

## 2. 결정(Fable 전결, DECISIONS D159) — 게이트 = 세 검사, 모두 통과해야 합격
1. **절대 시각(A)**: 참값 = 음향 발화 시작. 정의를 코드·테스트로 고정한다 — 원본 mp3(44.1k mono), 무음 = `|a| < 0.012`(trim 과 같은 문턱) 가 **≥ 150ms** 이어진 구간, 발화 시작 = 그 뒤 첫 문턱 초과 샘플. 문장 시작(= trim 지점 + 0.03)도 참값에 넣는다. 참값 ↔ 정렬 어절 대응은 **순서·단조**(문장 안 발화 시작 k 번째 ↔ 정렬 어절 시작 중 ±300ms 안 가장 가까운 것, 단조 증가 유지). 대응 없는 발화 시작은 **실패로 300ms 로 계상**(빼지 않는다). 기준 그대로 **중앙값 ≤ 60ms · p90 ≤ 120ms**. 모집단 = 호르무즈 45 + fed 45(플랜에 쓰는 문장) + 문장 시작. 시제품 21/51 → 통과 예상.
2. **문장 안 어절 — 간격 일치**: 같은 문장 안 연속 어절(둘 다 쉼 뒤 아님)의 간격 차 `|(MMS_b − MMS_a) − (edge_b − edge_a)|`. 차이를 쓰므로 edge 의 상수 치우침이 소거된다(상수를 고르지 않는다 — C 와 다름). 기준 **중앙값 ≤ 60ms · p90 ≤ 120ms**. Fable 이 시제품 행으로 계산: n = 477, 중앙값 **23ms · p90 64 · p95 83 · 최대 163**, 부호 중앙값 −2 → 통과. 이 검사가 "문장 안은 검증 못 한다"(R-0195 A 의 단점)를 메운다. B(faster-whisper)는 새 의존성·모델이 늘고 그것도 참값이 아니므로 **이번에는 넣지 않는다**(이 검사가 미달이면 그때 decision_request).
3. **제작 음성(Supertonic)에서 1 번 반복**: 호르무즈 45문장을 Supertonic M3 ×0.95 로 합성한 음성(V1 캐시)에 MMS 정렬 → 음향 발화 시작 게이트 같은 기준. 제품이 쓰는 음성에서의 통과가 실제 합격이다. 청크 무음(0.3초)·쉼 모두 참값 표본이 된다.
4. **이동 불변 테스트**(픽스처, 네트워크 없이): 같은 음성 앞에 0.5초 무음을 붙이면 모든 어절 시각이 0.5초 ± 20ms 옮겨진다(절대 기준점 검증). 픽스처 게이트 테스트(10문장)는 1·2 방식으로.

edge 대조표(raw 109/267, 문장 안 +102)는 run_log 에 **참고**로 남긴다(게이트 아님).

## 3. 기록·전파
- **TTS-AP-082** append(`docs/ANTIPATTERNS/TTS_ANTIPATTERNS.md`): "edge-tts WordBoundary 는 절대 시각이 아니다 — 문장 시작 0.1초 고정, 쉼 앞 경계 = 쉼 시작, 문장 안 약 100ms 이름(851어절 음수 0). 측정: Opus 93문장, Fable 호르무즈 45문장(문장 시작 +285ms, 쉼 뒤 +254ms). 구조적 조치: 정렬 참값은 음향 발화 시작(D-0165), edge 경로는 V4 에서 삭제(P2)". DEVLOG 한 줄.
- 현 골든 앵커가 0.1~0.3초 이른 것은 **지금 고치지 않는다**(edge 경로는 V4 삭제 대상, 손대면 P2·P12 위반). V3 에서 Supertonic + MMS 로 플랜이 바뀔 때 컷이 달라지는 사유 "시각(edge 치우침 제거)" 으로 `expected_deltas` 에 적는다(D-0152 §2-8).
- `docs/handoff/03`(TTS·정렬) 에 참값 정의 한 단락, `rules tts_rules.forced_align`(min_score·silence_sec 0.15·silence_thr 0.012·match_window_sec 0.3·gate {median_ms 60, p90_ms 120})는 규칙 파일 한 곳(P3).
- 참값 자체의 치우침(문턱 교차는 진짜 발화보다 10~20ms 늦다)은 run_log 에 적는다. 기준에는 반영하지 않는다.

## 4. 사용자 청취 표본(V3 산출물로)
R-0195 §4 의 클릭음 시트는 **사용자**에게 간다(Fable 은 들을 수 없다). V3 에서 호르무즈 Supertonic 음성 30초 구간 1개 + 문장 안 어절 10·쉼 뒤 5 의 앵커 시각에 클릭음을 섞은 mp3, 같은 구간의 자막 앵커 표. 콘티 판·전편과 함께 보낸다.
