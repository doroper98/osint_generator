## 2. 구현 요약
- 고르기: direction `stage_config.mercator.theme`(+ `theme_reason` 필수) → 장르 프로필 `stage.mercator.theme`(지정학 light). 프로필에 값 없음 = 오류(D-0171 §3).
- 시리즈: `rules/series_registry.yaml`(빈 시작), `[series-theme-mismatch]` hard, 중복 소속 = 로드 오류, 시리즈 소속이면 override warning 없음.
- 의미색: `colors.themes.light` 휘도 0.06·색상 불변(D-0172 C, 잠정). 지도 위 요소만(`map_c(view.stage, …)` — 무대 기준이라 아일랜드 안은 공통값). 카드·자막·HUD·엔딩·아일랜드는 지도 색 함수 미사용(테스트).
- 해안선↔국경: 공유 변만 국경(한 번만), 나머지 해안(물빛 얇은 선) — light 만, dark 는 종전 바이트.
- light 글로우 끔(`enabled: false` — YAML 1.1 `on` 함정 때문에 키 이름 변경), 글자 톤 짙게, 콘티 판 막지도 같은 테마.
- 대비: 렌더 프레임의 **지도 층 합성본**에서 측정(카드·패널 가림 배제). 필수 글자 4.5 hard, 경로 선 3 warning(컷·경로 중앙값). provenance `map_contrast` 측정표.
