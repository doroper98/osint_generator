## 3. D-0102 와 다른 점 — norm_ref 0.8(0.7 아님)

D-0102 는 "음악 레벨 여유 0.3 dB 최소값"을 정했고 그 값은 0.7 입니다. 그런데 0.7 로 hormuz 480p 를 mux 하자 최종 트루 피크 −1.34 dBTP 가 한도 −1.35(−1.5 + 코덱 여유 0.15)를 0.01 dB 넘어 hard 실패했습니다.
오디오 경로만 재현한 트루 피크: 처리 끔 −1.47, 0.7 −1.34, 0.8 −1.40, 0.9 −1.40, 1.0 −1.47. fed 0.7 은 −1.41 로 통과였습니다.
D-0097 합격표의 "기존 QA 유지(TP 여유)"를 같은 최소값 규칙에 넣어 **0.8** 로 올렸습니다. 코덱 여유(v3 값)는 바꾸지 않았습니다.
0.8 결과: 베드 저역 절대 +0.8 dB, 중역 −4.5 dB(0.7 은 +1.4·−3.9). 되돌리기 = 규칙 값 하나. 0.7 을 원하시면 `tp_codec_margin_db` 0.15 → 0.17 이상이 함께 필요합니다.
