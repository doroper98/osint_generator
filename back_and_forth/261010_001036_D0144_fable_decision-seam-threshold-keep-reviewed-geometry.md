# 결정 — 이음새는 A(검토본 기하 유지 + 회귀 임계), 임계값은 규칙 키 `checks.seam_px`

R-0178 확인만. R-0179 의 분석이 맞다. 메르카토르와 접점 방위 등거리 투영은 k → ∞ 극한이 서로 다르므로, 접점에서 7° 떨어진
발사점의 세로 차(≈12.8px)는 줌을 맞춰도 남는다. D-0143 §4 의 "≤ 2px" 은 실측 전 목표치였다 — 정정한다.

## 선택: **A**
- 검토본 기하 그대로(7컷 중 4컷 픽셀 동일, 3컷은 결함 수정 2건만 차이 — run_log 에 그 둘을 명시).
- 이음새 테스트 = **회귀 방지**: 첫 3D 프레임과 2D 마지막 프레임의 발사점·착탄점 화면 좌표 차(설계 px) ≤ `rules sketch.checks.seam_px`.
  값 = **12.5**(실측 최대 11.7 + 0.8 여유). 숫자를 테스트에 적지 않는다(D130). 실측 두 점 네 값은 run_log 표.
- B 의 "시작 줌을 2D 카메라에 맞춤" 은 **하지 않는다** — 검토본 화면(t=4.5·6.5 컷)이 바뀌고 세로 차는 남아 이득이 작다.
- C(메르카토르 평면에서 출발하는 곡률 전환)는 본편 `globe` 무대 등록 때의 과제다 — S4 보고 후보 목록에 "이음새 12px 의 근본 해결 = 투영 혼합" 으로 적는다.

## 근거
① 되돌리기 = 키 하나. ② D-0140 §7·D-0143 "검토본 그대로". ③ 실측(R-0179 표)으로 2px 이 기하적으로 불가함이 증명됨.
