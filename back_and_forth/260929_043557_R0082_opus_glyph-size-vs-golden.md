# 결정 요청 — 최소 글자 2%(glyph_size) 임계가 480p 골든과 충돌(D-0066 작업 5)

D-0068 확인: `label_hidden` 검사 푸시(hormuz 마커 전부 0% · hard 0 · 25컷 MAD 0, 랫클리프 v3 모스크바 2개 92%·87% 검출). 랫클리프 재실행(마지막 1회) 진행 중.

## 1. 실측 — hormuz 골든 25컷에서 실제로 그려진 글자(설계 480p px, 알파 > 0.01)
2% × 480 = **9.6px**. 이보다 작은 글자가 골든에 있다(크기 → 그리는 함수: 컷 수).

| 크기 | 화면 높이 대비 | 1080p 환산 | 그리는 곳(컷 수) |
|---|---|---|---|
| 7.5 | 1.56% | 16.9px | 미디어 태그 PHOTO·VIDEO(`media_tag` 4), 기사 카드 ARTICLE 태그(2) |
| 7.8 | 1.63% | 17.6px | 미디어 캡션 출처 줄(`media_caption` 4), 기사 카드 메모(2), 엔딩 카드 라이선스(1) |
| 8.5 | 1.77% | 19.1px | 기사 카드 날짜·매체(2), 컷아웃 출처 줄(1), 엔딩 카드 제목줄(1) |
| 9.2 | 1.92% | 20.7px | 엔딩 카드 항목(1) |
| 9.5 | 1.98% | 21.4px | 도 이름(`draw_labels` 5), 카드 출처(2), 기사 카드 본문 보조(2) |

규칙 `layout_480p.min_font_px: 9.5`("화면 높이 2% 규칙(엔딩 카드 예외)")와 09 §2 표("최소 글자 9.5px — 도 이름, 출처")도 이미 9.5 다.
즉 문자 그대로의 2%(9.6) 는 도 이름까지 걸고, 9.5 도 미디어 태그·출처 줄·기사 메타(7.5~8.5)를 건다. 모두 사용자 합격 수치다.

## 2. 선택지
- **A(권고)**: 임계 = `layout_480p.min_font_px`(9.5, 09 §2 표의 "최소 글자"), **hard**. 예외 역할 레지스트리 `qa_checks.glyph_size_exempt`:
  `end_card`(규칙에 이미 있는 예외), `media_meta`(미디어 태그·캡션 출처 줄·기사 카드 태그/날짜/메모·컷아웃 출처 줄 — 권리·출처 표기용 메타 글자).
  그리는 함수가 `text(..., role=…)` 로 역할을 밝히고, 예외 밖 9.5 미만 = hard. 판정은 설계 px(= 해상도 무관, 1080p 에서도 같은 결과).
  골든 hard 0, 새 연출이 본문·라벨·카드 글자를 9.5 미만으로 만들면 잡힌다(현재 연출 LLM 은 크기를 못 정하므로 주로 새 패널·레이어 회귀 방지).
- **B**: 임계 9.6(문자 그대로 2%) + 같은 예외 + `draw_labels` 도 이름 예외 추가. 규칙 문구와 맞지만 도 이름 9.5 를 예외로 빼야 한다.
- **C**: glyph_size 를 warning 으로(보고만). 골든 무변경, 막는 힘 없음.

## 3. 근거(A)
① 되돌릴 수 있음(규칙 값·예외 목록). ② 09 §2 표가 최소 글자를 9.5 로 명시, 규칙 파일도 9.5. ③ 저장소 실측: 2% 미만 글자는 전부 출처·메타·엔딩 카드 —
C9(권리 표기)가 요구하는 글자라 크기를 키우면 합격본이 바뀐다(글자 확대 = 사용자 합격 수치 변경, D-0066 §3 금지).
사용자 판단이 필요하다고 보면(메타 글자를 1080p 휴대폰 판독 관점에서 키울지) §7 사안으로 올려도 된다 — 그 경우 A 로 두고 기록만.
