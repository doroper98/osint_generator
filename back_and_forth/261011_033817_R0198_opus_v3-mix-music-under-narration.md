# V3 §3-2·§3-4 — Supertonic 믹스가 "내레이션 구간 음악" hard 범위를 0.003 dB 넘는다. 처리 방식 결정 요청

## 1. 쟁점
`engine.mux` 전편이 오디오 QA hard 로 멈춥니다: `내레이션 구간 음악 -9.00 dB — 범위 [-13, -9]`(rules `audio.qa.music_under_narration_db`, D-0118 D103).
나머지 항목은 모두 범위 안입니다: 최종 −14.1 LUFS · TP −1.55 · mix 피크 0.9507 · 문장 RMS 이상치 0 · 저음 보강 +5.34 dB.
콘티 판 음량도 −14.1 LUFS · TP −1.55 입니다. 720p 영상 렌더(6255프레임, 396초)는 끝났고 mux 만 멈췄습니다. D-0167 §3-2 "벗어나면 decision_request" 에 따릅니다.

## 2. 원인(측정 — 같은 믹서·같은 음악·같은 연출, plan 만 다름)
| 내레이션 | 내레이션 RMS | 음악 RMS(내레이션 구간) | 음악 − 내레이션 | 내레이션 길이 |
|---|---|---|---|---|
| edge InJoon(옛) | −16.66 dB | −26.49 dB | **−9.83** | 240.8초 |
| Supertonic M3(새) | −17.50 dB | −26.50 dB | **−8.997** | 209.1초 |

음악 쪽은 같습니다. 믹서는 문장을 피크(`narration_peak 0.8`)로 정규화합니다. Supertonic 은 같은 피크에서 평균 음량이 **0.84 dB 낮습니다**(파고율이 높다).
그래서 사용자가 edge 로 합격시킨 음악/내레이션 균형이 Supertonic 에서 0.84 dB 음악 쪽으로 기울었습니다. 최종 loudnorm 이 전체 음량은 맞추므로, 들리는 차이는 이 **비율**뿐입니다.

## 3. 선택지
| 안 | 내용 | 장단 |
|---|---|---|
| **A(권고)** | `rules audio.bed_gain` 0.47 → **0.43**(−0.77 dB). 호르무즈 예상 −9.77 dB = edge 시절 균형(−9.83)으로 복원 | 숫자 1개. 최종 loudnorm 뒤 들리는 결과 = 사용자 합격 균형. V4 에서 edge 가 지워지면 모든 영상이 Supertonic 이라 전역 값이 맞다. 콘티 판·전편 다시 믹스(렌더 영상은 재사용) |
| B | 내레이션을 피크가 아니라 RMS 목표(예: −16.7 dB)로 정규화하는 믹서 변경 + 규칙 키 | 원리상 목소리 독립. 믹서 코드·규칙 키·기존 골든 오디오 지문이 바뀌는 큰 변경. 피크가 master_peak 에 가까워져 리미터 부담 |
| C | `narration_peak` 0.8 → 0.87 | 같은 효과지만 mix 피크 0.95 → 1.0 가까이 — master_peak 0.97 위험. 비권고 |
| D | 범위 완화 [-13, -8.5] | 사용자 결정 범위(D103)의 임의 완화 — 비권고 |

## 4. 권고
**A**. 적용 뒤 `audio.mix` → 콘티 판 다시 → 전편 mux. QA 표(이번 값·edge 비교·A 적용 뒤 값)를 run_log 에 남깁니다.
bed_gain 은 규칙 파일 값이라 사람 승인 사항입니다(P11). 사용자 청취(V3 합격 조건)에서 같이 확인받는 것을 제안합니다.

## 5. 막히는 범위
전편 mux·사용자 청취 묶음(콘티 판·전편 mp4)만 막힙니다. 프리뷰 25컷 기준선(phaseV3)·컷 대응표·나란히 시트·클릭음 표본·expected_deltas·테스트는 끝냈습니다.
판단 1건(되돌릴 수 있음, 기록): 720p 프로파일 `clip: null` 이 `load_clip` 프로파일별 경로 규칙(D-0074)과 어긋나 클립 있는 영상을 720p 로 못 냈습니다.
D-0074 기준(16:9 정확·폭 64 배수·필요 폭 이상 최소)으로 필요 폭 990 ÷ 2.25 × 1.5 = 660px → `clip: [704, 396]` 로 바꾸고 `media_fetch --res 720p` 를 돌렸습니다.
