# 결정 — UF-149 "막대 차트가 성의 없고 전형적": agents_reviewer 디자인 시트 v8.6.0 의 차트 어휘를 영상 문법으로 흡수한다(종류를 늘리지 않고 **표현**을 바꾼다)

## §0 사용자 원문(2026-10-30, 원장 UF-149)
> "https://doroper98.github.io/agents_reviewer/samples/report_design_sheet_v8_6_0.html 여기에 나온 차트 문법들을 쓸 순 없을까? 너무 막대 차트가 성의가 없고 전형적이야. 직관적이면서도 비쥬얼하게 전달력을 갖출 수 있도록 해야해"

감독이 시트(로컬 클론 `samples/report_design_sheet_v8_6_0.html`·`.charts.js`, 42 견본)를 읽고 영상에 맞게 옮겼다. 시트는 **보고서 지면** 규약이라 그대로 붙이면 C0 "보고서 화면" 이 된다 — 가져오는 것은 **어휘**(형태·농도·질감·라벨 규율·모션 원칙)이고, 무대는 그대로 시간축 한 세계다.

## §1 흡수하는 어휘 6가지(시트 §6.1~6.6·§07) → 영상 규칙 키
1. **형태 인코딩 — 속빈/채움**(시트 "캡슐과 속빈/채움"): **예상치 = 속빈 캡슐(윤곽선)**, **실제 = 채움 캡슐**, 같은 열에 겹친다. 예상·실제가 한 모양 안에서 읽힌다 — 두 막대를 나란히 세우지 않는다. 가이던스 = 속빈 범위 캡슐(위·아래 끝 + 가운데 눈금). `stage_timeline.series.bars.shape: capsule`(둥근 끝, 반지름 = 폭/2), `estimate.shape: hollow_capsule`.
2. **잉크 농도 사다리**(시트 §6.2): 분기 막대는 **최신 분기 하나만 accent(gold)**, 앞 분기는 단일 잉크 농도 사다리(3단 0.42·0.24·0.13 또는 4단). 부문 쌓임(DS/DX·DCAI/CCG/Foundry)도 **색이 아니라 농도 4단 + 직접 라벨**. 차트당 accent 는 한 요소. `series.bars.ink_ladder: [0.42, 0.24, 0.13]`, `stack.ink_ladder: [0.32, 0.20, 0.13, 0.08]`.
3. **칸 질감 — 칸 하나 = 정해진 수량**(시트 §6.5 tick·rung·dot): **셀 수 있는 값**(건수·인원·정수 금액 — 예: 점도표 참가자 수, 배당 주식 수, 공장 수)은 캡슐 대신 칸(rung)으로, 비율·지수·금액(조 원·십억 달러)은 캡슐. **렌더러가 단위로 자동 판정**(연출은 지정하지 않는다). 칸 질감을 쓴 차트는 하단에 "읽는 법" 한 줄(`series.key_footer`: "칸 하나 = 1조 원" 식) 필수 — 검사 `[unit-marks-caption]` hard.
4. **직접 라벨, 범례 금지**(시트 §6.3): 값 라벨은 대상 옆에 붙인다(막대 끝·캡슐 안). 범례 상자는 만들지 않는다. 이미 핀 라벨·끝값 판이 이 원칙이다 — bars 도 같게.
5. **선 어휘 — 관계는 dash 로**(시트 §6.3, 지경학 막·지도): 동맹·협력 실선 1.4 / 충돌·봉쇄 dash 5,3 굵기 2.0(가장 굵다) / 영향·충격 2,3 / 전략·보조 1,3. 기존 route·relation 색 의미 위에 **dash 어휘를 추가**(`map_lines.relation_dash`). 실적 영상 act5(관세·수출통제·정부 지분)에 쓴다.
6. **모션 원칙**(시트 §07 "움직임은 데이터가 들어오는 방식을 설명할 때만"): 막대는 문장 앵커에서 **0에서 자라고**, 예상 캡슐이 먼저 떠 있다가 실제 캡슐이 그 안을 채운다(beat 면 넘치고 miss 면 못 미침 — 차이가 모션으로 읽힌다). 생키는 흐름 방향만 입자, 값은 건드리지 않는다. 장식 모션 금지.

## §2 패턴(45° 해칭)은 **쓰지 않는다**
시트의 패턴은 21 테마 모노 지면용이다. 영상은 색 토큰(accents)이 있고 해칭은 480p 에서 모아레가 난다 — 명목 카테고리도 농도 사다리 + 직접 라벨로. (시트 §6.1 의 "금지 조합" 은 그대로 교훈.)

## §3 실적 템플릿 다섯 막에 대입(D-0278 §3 갱신)
| 막 | 표현 |
|---|---|
| act1 예상 vs 실제 | 분기 열: 앞 분기 캡슐(사다리) → 발표 분기 **속빈 캡슐(예상)** 먼저 → 채움(실제)이 자라 넘치거나 못 미침 → 차이 라벨(코드) |
| act2 부문 | 같은 캡슐이 **농도 4단 쌓임**으로 갈라짐 + 부문 직접 라벨. 전분기 대비는 slope 한 줄(두 열 사이 연결선)로 |
| act3 가이던스 | 다음 열에 **속빈 범위 캡슐**(15~16) + 컨센서스 속빈 점(17.1) — 겹치지 않음이 한눈에 |
| act4 주가 | 일별 점 선(시트 line · 일별 점) + 발표일 핀 + 시간외 **속빈 점**(창 라벨 "시간외") |
| act5 지경학 | 지도 + dash 어휘 관계선 + 국기 원 |

## §4 산출(T2 스케치 재작업 — 요소마다 따로, D-0302 ⑤)
1. `bars` 스케치 **재렌더**: 인텔 매출 5분기 캡슐 + 사다리 + accent 1 + 직접 라벨 — 2컷(자라기 전·후).
2. `estimate` 스케치: 속빈→채움 2컷(예상 떠 있음 / 실제 채움 beat). 컨센서스 레코드가 생기면.
3. `stack` 스케치: 농도 4단 + 라벨 1컷. 4. `band` 가이던스: 속빈 범위 캡슐 + 속빈 점 1컷.
5. 워터폴·생키는 **뒤로**(인텔 GAAP→비GAAP 브리지가 있으면 워터폴 1컷, 생키는 삼성 매출→부문 흐름 1컷 — 입자 모션은 방향만).
각 컷은 **실제 레코드·실제 엔진**(목업 금지), artifacts/econ-template-2026 → R(요소마다 따로). 감독이 보고 사용자에게 요소별 승인을 묻는다. 규칙 키 값은 전부 "감독 제안(사용자 합격 값 아님)" 주석.

## §5 장치(C12)
`[unit-marks-caption]` hard · `[one-accent-per-chart]` hard(차트당 accent 요소 1) · `[legend-forbidden]` hard(범례 상자 0) · 기존 `[bars-from-zero]`. 원장 UF-149 guards 에 rule 키·check·test. 시트 §6.1 "금지 조합" 은 `docs/handoff/` 참고 줄로.

## §6 보충(UF-153, 2026-10-30) — 시트 §6.4 매트릭스의 다섯 종을 실적 템플릿에 명시 배정(종류는 series 스타일 옵션으로, 독립 패널 아님)
사용자 원문: "내가 알려준 경로(…#s6-4)의 이런 차트들도 적극적으로 고려해볼꺼지?" — 그렇다. 배정:
| 시트 종류 | 영상 자리 | 데이터 | 표현(시트 흡수 메모 그대로) |
|---|---|---|---|
| **bullet** | act1·act3 — 실적 vs 컨센서스·가이던스 | 실제(filing) + 예상(press_cited) | 실적 = 채움 캡슐, 목표 = 얇은 세로 표식, 달성률 % 세리프 직접 라벨. D-0308 ① "속빈→채움" 의 정본 형태 |
| **range_bar · before_after(덤벨)** | act2 — 부문별 전분기→이번 분기 / act3 — 컨센서스→실제 | 부문 레코드 2시점 | 속빈 원 = 이전, 채움 원 = 이후, 사이 구슬. 항목 ≤8 |
| **diverging_bar** | act1·act2 — 부문별 y/y 또는 예상 대비 ±% (코드 계산) | 부문 레코드 | 0 기준 좌우, 감소는 --down 색, 값 라벨 바깥 |
| **slope** | act2 — 1년 전→지금 부문 구성비 변화(3~7 항목) | 부문 레코드 | 두 시점, 상승 accent 1, 나머지 농도. 8개 넘으면 덤벨 |
| **bump** | 공통 고리 컷 / 시장 점유율 순위(데이터 있을 때만) | 순위 레코드(출처 필수) | 단조 곡선, 1위만 accent |
- 전부 **같은 시간축 세계 안의 series 스타일**(`style: bullet|dumbbell|diverging|slope|bump`)로 구현 — 아일랜드 카메라가 그 열로 가서 보여 준다. 독립 패널·슬라이드 금지(UF-135).
- T2 스케치 목록 갱신: 다층 아일랜드 4컷(D-0309) → bullet 1컷(예상치 레코드 뒤) → 덤벨 1컷(부문 전분기→이번 분기) → diverging 1컷(부문 y/y) → slope 1컷(부문 구성비) → 가이던스 범위 → 워터폴·생키. bump 는 순위 레코드 있을 때.
