# 판정 — artifacts a7e4476(가이던스 인셋·slope C2 인셋·40초 A 컷). ⑧ 재작업, ⑨ 라벨 재작업, 40초 통과

눈으로 본 프레임: t2_inset_guidance p_0008/12.5/17.5·sheet, t2_inset_slope p_7.5/13/17.5·sheet, t2_multilayer_v5 p_36.5/40.0.
데이터는 다시 따지지 않는다(D-0319·D-0320 그대로). 아래는 화면 문법만.

## 1. 40초 컷(missing 안 A) — 통과
- 10월 29일 핀(점+고리)·점선·라벨 자리 깨끗하다. 일별 "자료 없음" 글자 없음. 그대로 둔다. 사용자 승인은 내가 묻는다.

## 2. ⑧ 가이던스 인셋 — 재작업(세 가지)
1. **"빈 막대"가 화면에 없다.** 내레이션은 "회사가 제시한 매출 범위를 빈 막대로 띄워 보겠습니다"인데, 4분기 자리에는 15~16 높이의 **둥근 캡슐**(지름 ~8px)과 작은 동그라미만 있다. 캡슐의 둥근 끝은 막대 둥글기 금지(UF-155 계열, `bars.top_radius 3`)에도 어긋난다.
   → 4분기 자리에 **다른 막대와 같은 폭의 속 빈 막대(테두리만, 0→16)**를 세우고, 15~16 구간만 **빗금 또는 반투명 띠**로 채운다(범위가 막대의 머리임이 보이게). 시장 예상 17.1 은 그 위 속 빈 동그라미 + 짧은 가로 획. 둥근 끝 금지, 위 모서리 3px 만.
2. **인셋이 범례 목록이다.** D-0318 의 열 확대 인셋은 "같은 값·축척 불변, 열을 키운 것"인데 지금 인셋은 글줄 셋(시장 예상/가이던스/예상 대비) 나열이다.
   → 인셋 = 4분기 열을 키운 그림: 속 빈 막대·띠·동그라미가 그대로 커지고, 옆에 직접 라벨 "가이던스 15~16", "시장 예상 17.1", "예상 대비 −2.1~−1.1". 수치 셋은 지금 그대로 유지(D-0319).
3. **오른쪽 빈 띠.** x축이 2027 2분기까지 뻗는데 4분기 뒤는 비어 있다(`[axis-empty-band]`가 왜 안 잡았는지 확인).
   → 축 끝 = 2027 1분기 경계(라벨 하나 여백)까지만.

## 3. ⑨ slope(C2) 인셋 — 데이터·구도 통과, 라벨 재작업
- 통과: DS 33.1→147.1 accent 1, 나머지 농도, 각주 "부문 간 내부 매출 포함"이 출처 줄에 있다. 두 시점 머리 줄도 좋다.
- 재작업: **SDC(8.1→8.0)·하만(4.0→4.3)이 한 선·한 점으로 겹친다.** 왼쪽 라벨 사다리(48.4·33.1·8.1·4.0)는 점에서 떨어져 내려와 "33.1"이 SDC 점 옆에 서 있다 — 어느 점의 값인지 헷갈린다.
   → 디자인 시트 잉크 사다리 규칙: 라벨 최소 간격(글자 높이 ×1.1)을 두고 밀어낸 뒤 **가는 리더선**으로 자기 점에 잇는다. 오른쪽 "SDC 8.0 / 하만 4.3"도 같은 처리. 선 두 개가 거의 포개질 때는 농도 차(위 선 진하게, 아래 선 더 옅게)로 구분.

## 4. 공통 — 출처 줄이 격자선과 겹친다(사용자 규칙 "선과 글씨 겹침 금지", UF-155)
- 가이던스·slope 두 판 모두 출처 두 줄이 0 기준선 아래, x 라벨 위의 **플롯 상자 안**에 있고 세로 격자선이 글자를 관통한다(p_0008 확대 확인).
   → 출처 줄을 플롯 상자 밖(x 라벨 아래 패널 여백)으로 옮기거나 격자선을 기준선에서 끊는다. 규칙 키 하나(`econ.source_line.placement`)로 두고, 겹침 린트가 **격자선 ↔ 글자**도 세도록 보강(지금은 글자 ↔ 글자만 세는 것으로 보인다 — 확인해 적어라).
