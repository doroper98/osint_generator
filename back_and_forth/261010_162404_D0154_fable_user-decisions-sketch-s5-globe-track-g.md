## 2. S5 (v5.12.0) 스케치 후속 — Opus, V1 뒤·Q0 앞. 테스트 ≥ 5
1. **주석 문구 교체(#3)**: 세 spec `notes.source_lines` 의 탐지 줄 text → "탐지 거리 표현은 공개 자료를 토대로 한 추정값". SK-H1 영향 없음(숫자 없음). 기준 프레임 중 그 줄이 보이는 컷(d1 20.5·27 등)은 **의도된 차이**로 `reports/phaseS5/` 에 전/후 시트 + 픽셀 비율 표, 나머지 컷 0.000 % 확인.
2. **화살표 부드럽게(#8)** — 원인(Fable 실측 `sketch/campaign/arrows.py:27`): 자란 길이를 `np.searchsorted(L, L[-1]·prog)` 로 **스플라인 꼭짓점 단위(정수 k)** 로 자른다. 꼭짓점 사이 길이만큼 끝점이 건너뛰고, 꼭짓점이 `AR.spline`(16/구간) 뿐이라 24fps 에서 계단이 보인다. 고치는 법: 끝점을 **호 길이 보간**(k−1·k 사이 분수 위치)으로 두고 끝 접선도 보간, 스플라인 표본 수는 규칙 키(`sketch.campaign.arrow.spline`)를 화면 길이 기준(예: 1 표본 ≤ 2 px)으로 바꾼다 — 값은 규칙 파일. 띠 폭 보간(`half`)·그라데이션·화살촉은 보간된 끝점 기준. 라벨 위치(`mid`)도 보간 경로에서.
   - 테스트: prog 를 0.01 간격으로 올릴 때 끝점 이동 거리가 **단조·상한(규칙 키 max_step_px)** 이내, 프레임 간 꼭짓점 점프 0, 1.0 에서 원래 끝점·화살촉 동일.
   - 기준 프레임: 성장 중인 컷(20·30.5초)은 바뀐다 → 의도된 차이 표. 완성된 화살표 컷(38.5 이후)은 0.000 % 여야 한다(끝 상태 보존 테스트).
   - 콘티 판 재검토용 `sketch_campaign.mp4` 전편을 사용자에게(부드러움은 영상으로만 판단).
3. 22 §6 표를 "확정" 열로 갱신(1~6 확정, NLL 공식 좌표 교체는 본편 전 과제로 §7 이동), SKILL 두 문장. DECISIONS D150 은 Fable 기록.
4. S5 끝 phase_report → Q0.

## 3. 트랙 G — 3D 탄도 궤적 장면 본편 등록(사용자 결정 (a) + #7) — 착수는 별도 kickoff D(Fable)
자리: **Q4b 뒤, Q5 앞**(지도 데이터 층·LOD 가 먼저 안정돼야 지구본 텍스처·라벨을 같은 공급자로 만든다). 지금은 범위와 설계 질문만 고정한다.
- 범위: 무대 `globe` 레지스트리 등록(`rules registries.stages`), 이벤트 `arc`(탄도 궤적·고도 단면·레이더 볼륨) 등록, direction 숏 모델(2D (x,y,w) ↔ 3D (lon,lat,alt,tilt,az) 혼합), **투영 혼합**(메르카토르 ↔ 접점 방위 등거리 kR 구 — D137 이음새 ≈12px 를 혼합식으로 0 에 수렴), 콘티 판 자리표시, 검사(SK-H6 수평선·C1 3D 연속성 → 엔진 checks 로 승격), provenance.
- 설계 질문(kickoff D 에서 Fable 결정, 사용자 고유 사항은 사용자): ① 2D 숏 모델에 3D 축을 더할지 별도 숏 종류로 둘지 ② 혼합 구간의 라벨·국경·EEZ 층을 어느 투영에서 그릴지 ③ 지구본 텍스처를 Q4b 공급자(DEM·해저)에서 생성할지 ④ 근접 숏(22 §7) 포함 여부(사용자: 볼륨으로 보이게 → 포함 권고) ⑤ 내레이션 앵커와 비행 진행률 연결.
- 산출: 호르무즈가 아니라 **미사일 사건 본편 1편**(2023-07-12 또는 2024-10-31 spec)을 원고 → 콘티 → 본편 순서(C8.6)로 끝까지 — 등록의 합격은 본편 영상.

## 4. 집게(pincer) 설명(사용자 #9)
전황 스케치의 `pincer` 는 **남북 두 갈래 진격 화살표가 만나는 순간**(1942-11-23 소베츠키)을 찍는 점·태그다. 집게(鉗)처럼 양쪽에서 조여 닫히는 모양이라 붙인 이름이고, 화면에는 "11.23 소베츠키 — 남북 집게가 만남" 태그가 뜬다. 22 §6 의 "집게 예약 상자" 는 그 태그가 사라진 뒤에도 라벨 충돌 회피용 상자가 남아 있는 원본 동작을 말한다(그대로 둠).
