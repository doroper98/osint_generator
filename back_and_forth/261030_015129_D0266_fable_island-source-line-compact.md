# 결정 — 아일랜드 출처 줄: **B + C(합치고 옮긴다)**, 줄 수 상한은 2 유지(3 은 폴백 키로만)

- **B 같은 매체 조각 합치기**: 한 레인의 레코드 출처가 같은 매체(FRED(세인트루이스 연은))면 매체는 한 번, 원출처·기준 시점은 " · " 로 잇는다(코드 — `engine` 출처 줄 조립, 규칙 키 없음). 예: "FRED(세인트루이스 연은) · 원출처 연준 이사회·H.15 · 2026년 8·9월 기준".
- **C 전망 출처는 전망 띠 안 태그로**: SEP 출처("연준 FOMC 경제 전망 요약 2026-09-16")와 고정 문구("참가자별 전망이며 약속이 아님")는 레인 출처 줄이 아니라 **전망 음영 띠 위·아래의 작은 태그 두 줄**(amber, 기존 추정 태그 글자 크기 — `rules` 추정 태그 키 재사용)로 옮긴다. 20 §5.2 의 고정 문구 의무는 화면 어디든 보이면 충족이다(위치만 바뀐다). 축 범위 표기("축 범위 n~m%")는 레인 출처 줄 끝에 그대로.
- **줄 수**: `island.source_wrap_lines_max` 는 **2 유지**. B+C 뒤에도 넘치면 그때만 3 으로 — 규칙 키 값 한 줄, R 에 넘친 폭(px)을 적어라. 3줄 작은 글자가 아일랜드 안을 채우는 것은 UF-137 부류(화면이 글자로 꽉 참)라 기본값으로 두지 않는다.
- 근거: 판정 ①(모두 되돌리기 쉬움) · 사용자 의견 UF-137(붐비는 화면) · 20 §5.2(문구 의무는 위치 무관).
- 테스트 1(같은 매체 합치기), 프리뷰 컷 1장(금리 레인 출처 줄 + 전망 띠 태그)을 R 에.
