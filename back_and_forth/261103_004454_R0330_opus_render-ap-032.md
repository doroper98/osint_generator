# D-0624 — RENDER-AP-032 표준 글꼴 렌더 설정 장치, 단독 커밋 **fddc5526**(fddc55265dc2eecd0a7ef189bcb4585960fb2a10)

## 1. 설정 파일 — `config/fontconfig/fonts.conf`(경로 = config.yaml `engine.fontconfig.file` 한 곳)

- `/etc/fonts/fonts.conf` 를 include 한 뒤 `<match target="pattern">` 에서 일곱 속성을 assign 합니다. 컨테이너 고유 경로는 없습니다.
- `fc-match -v` 비교(표준 = R-0310 §3 설정, 시스템 = 이 컨테이너 기본, 새 파일 = 추적 파일):

| 속성 | 시스템 | 표준 | 새 파일 |
|---|---|---|---|
| antialias | True | True | True |
| hinting | **False** | True | True |
| hintstyle | **0** | 1 | 1 |
| autohint | False | False | False |
| rgba | **5**(none) | 1(rgb) | 1 |
| lcdfilter | **0** | 1(lcddefault) | 1 |
| embeddedbitmap | True | True | True |

- 엔진 글꼴마다 같은 비교(표준 = 새 파일, 일곱 속성 모두 같음): IBM Plex Sans KR · Medium · SemiBold, GmarketSansBold · Medium, IBM Plex Mono SemiBold · Medium, Noto Serif CJK KR · Bold, (참고) DejaVu Sans. 시스템 쪽은 전부 위 표의 굵은 넷이 다릅니다.
- 시스템 차이의 원천은 `/etc/fonts/conf.d/12-unhinted-grayscale.conf` 입니다. 패키지 소속이 없습니다(dpkg -S 없음). 컨테이너 준비가 넣은 파일로 보입니다.

## 2. 한 곳 — `engine/fontenv.ensure()`

- FONTCONFIG_FILE 을 추적 파일로 정합니다. 다른 값이 있으면 덮어쓰고 stderr 에 `[fontenv] FONTCONFIG_FILE A → B` 한 줄을 남깁니다.
- 그다음 `fc-match -v <probe_family>` 의 hinting·hintstyle 을 `engine.fontconfig.expect` 와 대조합니다. 다르면 `FontRenderConfigError` 로 멈춥니다. fc-match 실행이 안 돼도 멈춥니다.
- 부르는 곳: `engine/style.py` 첫 실행 문(규칙·글꼴을 읽기 전), `tests/conftest.py` pytest_configure, 엔진 밖 글자 도구 `tools/strike_demo/render_demo.py`·`multi_demo.py`.

| 렌더 경로 | 지나는가 | 근거 |
|---|---|---|
| 본 엔진 콘티 판·프리뷰·전편(`engine.render`) | 예 | import 시 engine.style → ensure. 청크 하위 프로세스도 같은 import + 환경 상속 |
| terrain3d 엔진 레이어·미리 렌더(`engine.layers.terrain3d`·`engine.terrain3d_prep`) | 예 | engine.style import. node/Chromium 하위 프로세스는 지정된 환경을 상속 |
| 스케치(`sketch.war`·`sketch.campaign`·`sketch.missile` CLI) | 예 | `__main__` import 에서 지정 확인(env -u 새 셸). 3D(view.html) Chromium 은 상속 |
| 시험 | 예 | conftest pytest_configure |
| 글자 도구 `tools/strike_demo` | 예 | 직접 ensure |
| gate-view·design_sheet | 해당 없음 | 글자를 그리지 않음(텍스트·HTML 출력) |

- 강제: `tests/anti_inertia/test_fontconfig_guard.py`. engine·sketch·tools·orchestrator·script·audio 에서 글자를 그리는 모듈(show_text·text_path·select_font_face·PangoCairo)이 engine 을 import 하지 않으면 실패합니다.

## 3. 시작 점검 시험

`test_fontconfig_guard.py` 7개(전부 통과):
- 설정 파일이 저장소 안 상대 경로이고, /etc/fonts include·일곱 assign 이 있고, 컨테이너 경로가 없다.
- 표준 파일로 점검 통과.
- **비표준(추적 파일 사본에서 hinting false·hintnone)이면 `FontRenderConfigError`** — 사고 상태 재현.
- 환경 변수가 추적 파일로 지정됨.
- engine.style 첫 실행 문이 ensure.
- 글자 그리는 모듈 전수.
