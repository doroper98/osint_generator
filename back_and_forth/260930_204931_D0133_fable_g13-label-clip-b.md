# G13 §D — 검수 hard 4: **B** 채택(코드 결함 먼저 → 회차 1회 → 남으면 A)

R-0157 접수. 슬롯(fe4cc05)·`--rounds`(8f55fcb)·v15(checks hard 0, 사진 place 는 LLM 이 옮김) 확인. prev/ 의 G12 판정을 실행 전에 치운 것 옳다(P9).

## 결정
1. **렌더 규칙(코드, P8 범위)**: 차트 아일랜드 안 마커 라벨이 아일랜드 상자 오른쪽 끝을 넘으면 라벨을 점 **왼쪽**에 붙인다(anchor 반전). 왼쪽으로도 넘치면 상자 안으로 클램프. 값은 `rules/video_rules.yaml island.chart` 아래 키로 둔다(예: `label_flip_pad`, 기본은 현 라벨 여백과 같은 값). **아일랜드 안 마커에만** 적용 — 지도·타임라인 무대 마커 경로는 건드리지 않는다(hormuz 골든 25/25 바이트 동일 유지가 조건).
2. **검사 `[island-label-clip]` hard**: 반전·클램프 뒤에도 라벨 글자 상자가 아일랜드 밖이면 오류. `qa_checks` 레지스트리·provenance 기록·문법(연출 필드 표 한 줄: "라벨은 아일랜드 안에서만 보인다, 오른쪽 끝 마커는 라벨이 왼쪽에 붙는다") 세 곳 동시(C7). 테스트 ≥ 2(반전 발생·hormuz 무변경).
3. **검수 2번(라벨 ↔ 출처 줄 겹침)**: 같은 커밋에서 라벨 세로 자리와 출처 줄 세로 자리가 겹치는지 검사로만 잡는다(`[island-label-clip]` 에 포함시키지 말고 warning `[island-label-overlap]`). 고치는 것은 연출 회차 몫.
4. 그 뒤 **추가 수정 회차 1회**(`--rounds 1`, 검수 판정 v1 입력). 1·3 은 연출이 고친다(코드가 카드를 옮기지 않는다).
5. 회차 뒤 검수 hard ≤ 2 → 480p·시트·artifacts·phase_report. **hard > 2 여도 A 로 진행**(480p 렌더·phase_report 에 "검수 hard N, 기준 미달" 명시). 게이트 ② 는 Fable 이 판단한다. 더 이상의 회차는 없다.

## 하지 말 것
- 검수 hard 를 줄이려고 검수 프롬프트·임계값을 바꾸지 않는다(P11).
- 규칙 값(6·0.38·0.15·3.0·슬롯 [594,212,236])은 그대로.
- `rm`·stash·백그라운드 대기 금지(D-0131·재기동 문안).
