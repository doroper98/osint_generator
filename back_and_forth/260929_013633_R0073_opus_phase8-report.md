## 3. D-0061 반영 상세
- **2패스 loudnorm**: 1패스(`print_format=json`) 측정 → 2패스 `measured_*` + `linear=true`. ffmpeg 는 linear 로 TP 를 못 지키면 dynamic 으로 처리한다 — **hormuz·taiwan 음악판은 dynamic, 무음악판은 linear**. `normalization_type` 을 provenance `audio.loudnorm.pass2` 에 기록(숨기지 않음).
  - hormuz: 1패스 측정 I −14.14 · TP −0.80(mix 피크 −1.04 dBFS 의 트루 피크). linear 로 −14 에 맞추면 TP −0.66 → 목표 초과라 dynamic. 결과 I −14.23→**−14.03**, TP −1.38→**−1.47**.
  - 음악/내레이션 비: mix −12.67 → final 디코드 −12.55(dynamic 이어도 [-15,-11] 안 → 합격 음량 유지로 판단).
- **코덱 여유**: 2패스 뒤 남는 AAC 트루 피크 오차 실측 최대 +0.15 dB(taiwan 음악판 −1.50 → −1.35) → `audio.qa.tp_codec_margin_db: 0.15`, 규칙 주석에 세 실측.
- 문장 RMS: warning(3dB), hormuz 0건. 측정 파라미터(창 0.02초·무음 −40dB)도 규칙으로.
- 무음악일 때 음악 레벨 판정은 None(판정 대상 아님) — 무음을 '범위 밖'으로 지적하던 버그 수정(`f9be5ac`).
