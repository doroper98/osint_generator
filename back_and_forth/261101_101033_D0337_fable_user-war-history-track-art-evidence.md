# 결정(사용자) — 전쟁사 트랙 착수. 별도 감독(Fable)+구현(Opus) 세션. 미술사 적극 연계

## 사용자 원문(2026-11-01, UF-206)
**"전쟁사는 별도 트랙으로 감독과 구현 세션 띄워서 진행하고, 전쟁사 세션에서는 아주아주 적극적으로 미술사와 연관시키고 미술 작품이나 인물 사진, 전쟁사적 기록과 사진을 캐입시키게 만들어. 즉 과거 전쟁은 미술과 기록, 현대 전쟁은 사진과 영상과 기록을 적극적으로 보여주는거야."**

## 1. 뜻(감독 해석 — 계획 D-0307 위에 얹는다)
- D-0307 §3 증거 층 셋(당대 미술·유적·지명 유래)은 "영상마다 ≥1" 이 아니라 **주된 화면 재료**다. 지도·전술 무대는 뼈대, 미술·기록·사진·영상은 살이다. 사용자 강도 "아주아주 적극적으로".
- **시대별 재료**: 고대·근세 = 회화·조각·모자이크·도기·주화·부조·사본 삽화 + 사료 인용(저자·권·절, PD 영역본). 현대(사진 이후) = 당시 사진·필름·보도 영상·공문서·지도 원본 + 기록. 인물 = 초상(회화·흉상·주화·사진).
- 미술 작품은 **그 시점을 묘사한 것**과 **후대의 묘사**를 코드가 라벨로 가른다(D-0307 §3-1 `period_art.contemporary_gap_years`). 후대 회화(예: 19세기 역사화)는 쓰되 "후대의 묘사" 라벨 의무. 사실 장면 AI 생성 금지(C9·G4-10) 그대로.
- 미술사 연계 = 작품을 보여 주는 데서 끝나지 않는다. 작품의 작가·연대·소장처·왜 그렇게 그렸는지(주문자·정치적 의도) 한 문장 — 전쟁 서사와 미술사 서사가 같은 시간축 위에서 만난다. 이것이 E10 미술사 트랙의 밑그림이 된다.
- 권리: Commons PD-Art·CC0·CC BY 만. 사진·영상은 rights_status 기록, 자료사진·자료영상 표기(C0 경계).
