# 칸나이 콘티 판 — media_density 하한을 고대 전쟁사가 채우지 못함(결정 요청 하나). 나머지 hard 는 고침

## 1. 상황

- 콘티 판 첫 시도는 렌더 전 checks hard 30건으로 거부됐습니다.
- 엔진 몫 둘은 고쳤습니다(54befec2). terrain3d 구간 경계에 암전을 요구하던 규칙, 구간을 빈 지도로 세던 규칙입니다.
- 연출 몫은 고쳤습니다(1f89b327). 시작 화면 32°(W 티어를 지중해 서부로 넓힘), 카드 자리·for, 노출 6초, drift 속도, 카메라 경계, aftermath 사상자 versus 패널(폴리비오스·리비우스, 원고 수치 그대로), 지명 마커입니다.
- 남은 하나가 **media_density** 입니다. 규칙은 사진·영상·컷아웃 분당 1.5(6.2분 → 10점) 이상이고, 사유로 통과할 수 없습니다(UF-139).

## 2. 채운 것과 못 채운 것

지금 사진 카드는 7점입니다: 흉상·셰켈 은화·타니트 비석·몬테포르티노형 투구(MET CC0, 새로 등록)·트럼불·Smith 사전·클로스.

더 찾은 후보 셋은 권리 때문에 뺐습니다.

| 후보 | 뺀 이유 |
|---|---|
| 팔카타(MET CC0) | MET 연대가 "possibly 2nd–4th century"로 기원전·후 표기가 없다 — 당대/후대 라벨을 정할 수 없다 |
| 마시니사 주화 | 사진 분류 CC-BY-SA-2.5(CNG 사진). PD 분류는 주화 나이 — RIGHTS-AP-001 과 같은 경우 |
| 폴리비오스 비석 | 사진 CC BY-SA 3.0(Livius). PD 분류는 부조 나이 |

- 남은 MET CC0 후보는 문장과 관계가 약합니다(아풀리아식 투구, 아풀리아 도기). 10점을 채우려고 넣으면 증거 층이 아니라 장식이 됩니다.
- 고대 전투는 당대 사진·영상이 없습니다. 화면 재료는 주로 지도·전술 무대·작품 카드·사료 인용입니다.

## 3. 결정 요청

- (가, 추천) 장르 war_history(고대·근세 — 시대 판정 symbol_set_by_year)의 media_density 에 **사료 인용 카드(quote.source)와 증거 패널(versus 등 사료 수치)**을 센다. 규칙 키 `media_beats.min_density_per_min` 은 그대로 두고, 세는 종류를 장르 프로필에 둔다. 칸나이 = 사진 7 + 인용 2 + 패널 1 = 10.
- (나) 하한을 장르별로 둔다(예: war_history ancient 1.0/분 — 칸나이 7점 ≥ 6.2). 규칙 개정(사람 승인).
- (다) 관계가 약한 MET 유물로 10점을 채운다(아풀리아식 투구 등). 추천하지 않습니다.
- 어느 쪽이든 사용자 판단이 필요한 규칙(UF-139 장치)이면 사용자에게 올려 주십시오.

## 4. 그 밖에 알릴 것

- 투구 카드는 deployment_12(노획한 로마 무기) 구간에 둡니다. 라벨은 Commons 설명대로 "에트루리아"입니다. 로마 투구라고 쓰지 않습니다. 이 짝이 부적절하면 빼겠습니다(그러면 6점).
