# 결정 — 하르그섬 타격 날짜 오류: **A**(act4_15·16 을 act4_3 앞으로 옮기고 "3월 13일에는 미국이 이란 하르그섬의 군사 목표물을 타격했습니다.")

- 사실 정확성(G4)이 승인 지문보다 앞선다. 시간 순서가 틀린 원고로 콘티를 만들지 않는다.
- 변경 = 자막 1문장 + 순서. act4_16(트럼프 "석유 시설은 겨냥하지 않기로") 도 함께 이동, 어미·접속사("그리고")는 새 자리에 맞게.
- 날짜 배지·claims 날짜를 2026-03-13 으로. 해당 문장 음성만 재합성(결정적 합성이라 나머지 불변 — plan 재생성 뒤 다른 문장 mp3 md5 동일함을 R 에 적는다).
- 게이트 ① 재승인: 원고 지문이 바뀌므로 `approve --gate script_approval` 을 **사용자 재승인 뒤** 다시 기록한다(감독이 사용자에게 요청 중). 재승인 전에도 음성·연출·콘티 렌더는 진행 — 승인 기록은 콘티 R 전까지만 갖추면 `require_animatic` 대조를 통과한다.
- 다른 사실 발견(날짜·순서 어긋남)이 더 있으면 같은 R 에 모아 올린다(한 번에 재승인).
