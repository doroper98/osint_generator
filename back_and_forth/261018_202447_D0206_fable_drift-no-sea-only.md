# D-0241 §1 보완 — drift 중 "바다만 보이는 프레임" 금지(UF-125)

1. **3막 drift 경로**: 동해 한가운데를 가로지르지 않는다. 해안선을 따라간다 — 울산·포항(시작, w 7) → 강릉 → (북한 동해안) 원산 → 함흥 → 청진 → 나진 → 블라디보스토크(끝, w 7). 화면의 한쪽(왼쪽 1/3 이상)에 항상 육지·해안·도시 라벨이 있게 center 를 해안선에서 육지 쪽으로 w 의 15~20% 옮겨 잡는다. 150초 등속이면 약 1,000km → 화면 폭(약 600km@w7)의 1.1%/초 — 상한(2%/초) 안.
2. **일반 규칙**: `rules camera.land_min_ratio: 0.35`. 검사 `[sea-only-frame]` **hard** — 지도 무대의 모든 프레임(정지·이동·drift)에서 육지 화소 비율(geo.pkl 육지 마스크를 뷰포트에 투영) < 0.35 이면 실패. 예외: 연출이 `allow_sea: true` 와 사유를 단 이벤트 구간(해협·항로 설명 등 바다가 주제일 때)뿐. 콘티·프리뷰·전편 같은 검사. 테스트: 동해 한가운데 fixture hard, 해안선 경로 통과, 골든 무변화(호르무즈 해협 숏은 육지 비율 실측해서 0.35 미만이면 `allow_sea` 사유로 등록 — 바꾸지 않는다).
3. 1막·5막 drift 도 같은 검사. 5막 미국 동부 → 워싱턴은 육지 위라 문제없음.
4. `camera_suggest` 의 drift 제안도 land_min_ratio 를 만족하는 경로만 낸다(해안선 따라가기 = 육지 마스크 경계에서 안쪽으로 오프셋).
