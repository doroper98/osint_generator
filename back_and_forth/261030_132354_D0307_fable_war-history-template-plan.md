# 계획 — E9 전쟁사 템플릿(현대~고대, 특정·불특정 시점) · 뒤이어 E10 서양미술사. 정본 = 규칙 파일, 디자인 시트는 규칙에서 생성, 스킬은 절차

## §0 사용자 결정·의견(2026-10-30)
- D288: 새 장르 = 전쟁사(1순위) → 서양미술사(2순위), 역사물 취소. 고대·로마 전쟁사 포함(감독 타당성: 기원전 날짜형·고대 지도 데이터·전술 무대 필요).
- 사용자 질문 "영상 스킬로 만들어야 해 아니면 디자인 시트처럼 만들어야 해?" → 감독 답(§1): 둘 다, 역할 분리.
- **UF-150**(원문): "그런 고대나 과거 전쟁사 같은 경우에는 진영이나 인물에 대한 묘사도 중요한데 그에 못지 않게 해당 시점을 묘사한 고대 미술사적 자료나, 유적지, 지역에 대한 유래에 대한 정보를 제공하는게 못지 않게 중요해." → §3 증거 층 셋(당대 미술·유적·지명 유래)은 **필수 요소**(선택이 아니다).
- 첫 사례(감독 가정, 사용자 이견 없으면): 2차 포에니 전쟁 칸나이(기원전 216년) — 작전 지도(알프스→트레비아→트라시메노→칸나이) + 전술 무대(양익 포위). 둘째 알레시아(기원전 52년).

## §1 세 층(정본 하나)
1. **규칙 = 정본**: `genres/war_history.yaml` + `rules/video_rules.yaml war_history:`(아래 §2~§4 전부 키로). 프롬프트는 규칙에서 생성(P3), 검사가 강제.
2. **디자인 시트 = 규칙에서 생성한 거울**: `tools/design_sheet.py <genre>` 가 규칙 값 표 + **실제 엔진 렌더 견본 컷**(부호 세트·날짜 표기·전선·증거 층마다 1컷) + 반례를 HTML 한 장으로. 손으로 값을 옮기지 않는다(agents_reviewer 시트 §00 원칙). 사용자가 보고 결정하는 자리. 규칙이 바뀌면 재생성(테스트: 시트의 값 = 규칙 값).
3. **스킬 = 절차**: `.claude/skills/campaign-front-map` 을 시대 세트·기원전 날짜로 넓힌다(규칙을 읽는다). 검토용 스케치·시트 견본 생성에 쓰고, 본편은 장르 프로필 + W0.

## §2 시대를 아우르는 장치
- **부호 세트** `war_history.symbol_sets: {ancient, early_modern, modern}` — 고대: 보병 직사각 블록(폭 = 병력 비례 옵션, 출처 있을 때만)·기병 쐐기·코끼리 점열·진영 색 2(토큰), 근세: 연대 블록·포병 삼각, 현대: APP-6 약식. 영상 날짜가 세트를 정하고 한 영상에 한 세트(`[symbol-set-mixed]` hard).
- **날짜형** `EraDate`: 천문 연도(기원전 216 = −215) + 정밀도 `{day, month, year, circa, period}` + 달력 표기(`calendar: roman|julian|gregorian|unknown`). 뱃지 "기원전 216년 8월 2일" / "기원전 3세기경" / 기간 띠. 원고 `date` 형식에 `-YYYY`·`c.-YYYY`·`-YYYY~-YYYY` 추가, 시간축·정렬·검사 전부 EraDate 로(가장 큰 공사 — 별도 단계 W1).
- **수치 정직성**: 병력·사상자 = 사료 귀속(`source_kind: ancient_text`, 저자·권·절 locator, 영역본 PD url) + 현대 추정 범위 띠(`band`, 학술 출처). `[casualty-unsourced]` hard.
- **지도 데이터**: 시대별 기반 `basemap_era: {ancient: [NE 지형, 국경 off, Pleiades 지명(CC BY), AWMC 해안·속주(CC BY), 로마 가도], modern: NE}` + `tools/fetch_ancient_geo.py`. 전장 축척은 Copernicus DEM 음영. 테마 dark(군사 기본값 D154).
- **전술 무대** `tactical`(stages 등록 전 proposed): 전장 수 km 축척, 부대 블록이 날짜·시각 키프레임으로 움직인다(한 번에 튀지 않음, 문장 앵커마다). 작전 지도 ↔ 전술 무대 전환은 카메라 연속(같은 좌표계 확대).

## §3 증거 층 셋 — UF-150(필수, 영상마다 ≥1 씩, `[evidence-layer-missing]` hard)
1. **당대 미술 자료** `period_art`: 그 시점을 묘사한 조각·모자이크·도기·주화·부조(예: 알렉산드로스 모자이크, 트라야누스 기둥). 레코드: 소장처·소장번호·제작 연대·재질·권리(CC0/PD-Art)·사진. **제작 연대 − 사건 연대 ≥ `period_art.contemporary_gap_years`(제안 150)면 "후대의 묘사"**, 그 안이면 "당대 묘사" 라벨을 코드가 붙인다(자료사진 규칙과 같은 장치, `[period-art-label-missing]` hard). 인물 초상은 흉상·주화로 — 동정(同定)이 불확실하면 "…로 추정되는 흉상".
2. **유적지** `site`: 전장·공성 유적·박물관 출토품(예: 알레시아 포위 흔적, 칼크리제). 지도 핀 + 현장 사진(Commons CC/PD) + 출토품 사진(CC0). 레코드에 발굴·보고 출처.
3. **지명·지역 유래** `toponymy`: 이름의 언어·뜻·유래(예: Cannae ← 라틴어 canna '갈대', 아우피두스 강가) + 출처 + 확신도 `{통설, 이설, 미상}`. 화면: 지도 핀 라벨 아래 한 줄 + 내레이션 1문장(장르 narration `etymology_once: true` — 사용자 선호). 출처 없는 유래는 쓰지 않는다.
- 진영·인물: 현대 국기 대신 **진영 배지**(코드 조판 진영명 + 색 토큰, 휘장 지어내지 않음). 인물은 period_art 초상(추정 표기).
