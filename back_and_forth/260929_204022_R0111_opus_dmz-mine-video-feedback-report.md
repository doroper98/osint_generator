## 5. 결정 요청

- **D1 (검증 규칙 — GOAL G4 영역, 사용자 고유 결정 가능성)** — S2. 다음 두 가지 판정을 추가할지 정해 달라.
  - 제안: "독립 origin ≥ 2 가 같은 공식 발언을 인용하면, 그 발언이 있었다는 사실을 corroborated 로 판정한다."
  - 제안: "'매체 X 가 ~라고 보도했다' 는 X 기사 자체를 1차 근거(verified)로 인정한다."
  - 이번 영상은 사용자 결정으로 라벨 표시만 껐다. 공개용 영상이면 이 문제가 다시 난다.
- **D2 (연출 프롬프트·검사 — P11 사람 승인)** — S3·S4. 세 가지를 제안한다.
  - (a) 원고 media 큐와 초상이 있는 인물에 대한 연출 문법 한 줄을 규칙에 추가한다. 예: "인물이 발언 주체인 문장에는 초상 뱃지 또는 해당 기사 카드".
  - (b) 좌표 근거 없는 사건 지점 마커를 경고하는 검사를 만든다. 예: 원고·claim 에 위치 수치가 없으면 marker sub 에 '좌표 비공개'를 의무화한다.
  - (c) 패널 장면에서도 인물 뱃지 자리를 둔다(M7).
- **D3 (운영)** — M1·M2. 새 프로젝트 준비 체크리스트를 WORKFLOWS W1 에 추가하자.
  - credits 음악 행
  - `--tts` 는 config 기본값 확인
  - 매체명 라틴 표기
  - 제목 길이
- **D4 (상태 머신)** — M6. render/deliver 이후 사용자 피드백으로 연출을 다시 하는 경로(예: `reopen --to direction`, 사유 필수)를 만들지 정해 달라. 지금은 CLI 직접 실행이라 manifest 에 v2~v4 기록이 없다.
