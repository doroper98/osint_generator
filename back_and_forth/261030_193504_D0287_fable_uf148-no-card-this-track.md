## 이 트랙에서 지금부터(엔진 삭제·검사는 쇼케이스 트랙이 sweet-galileo 에 구현 — merge 전엔 이 D 로 강제, merge 뒤 검사에 걸리면 고친다)
1. 연출에 `type: card` 이벤트를 쓰지 않는다. 이미 있으면 뺀다 — 내용이 자막에 있으면 삭제, 숫자·날짜면 marker label 또는 panel timeline 핀 라벨.
2. 자막·내레이션 문장을 화면 글자로 되풀이하지 않는다. 패널 제목·핀 라벨·marker label 은 짧은 명사구(날짜·공고 번호·지명·수치)만.
3. 사진의 기본 슬롯은 가운데 크게(블러 배경 안 액자 — 클립 액자 UF-141 과 같은 원칙). 구석 상자 금지. 기사 카드(article)·quote·panel(timeline·versus·dots)은 유지.
4. 앞선 D 의 "카드" 치환표:
| D-0283·0285·0286 표현 | 치환 |
|---|---|
| 허가제/등록제 대비 카드 | panel versus(항목 두 개, 명사구) 또는 자막만 |
| 2027-01-10 휴전 만료 카드 | 워싱턴 marker label "휴전 만료 2027.01.10"(축 밖) |
| 날짜 카드 11/15·11/18·11/24 | act4 panel timeline 핀 |
| "범위 밖: 앱·웹 / 범위 안: 현지 배치" 카드 | 자막만(화면 글자 없음) |
| 대변인·조시 발언 "직함 카드" | quote 이벤트(초상 없으면 직함 글자) |
| 동아지질 설명 카드 | 자막 + 기사 카드(토요경제 10/21) |
| 민감 국가 명단·최종 목록 미공표 카드 | 자막만 |
