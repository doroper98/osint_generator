# 결정(사용자) — 바닥 조판 방향 승인. 손실 막대 = B(잉크 사다리, 한 단계 진하게)

- 사용자 원문(2026-10-31, UF-203): 감독 질문 "이 조판 방향으로 가도 되는지 · 손실 막대는 A인지 B인지"에 **"응"**. 감독 해석: 방향 승인 + 감독 추천(B) 수용. 사용자가 A 를 말하면 그때 바꾼다.
- 적용:
  1. `t2_stage_v2/p_0016.50_ink_light` 의 문법이 경제 템플릿 **정본 조판**이다(D-0328 §1~§3). 손실 막대 = 잉크 사다리 면, 단 한 단계 진하게(0.24 수준, `bars.negative_fill: ink` + 농도 키) — 바탕과 구분되게.
  2. 원고 "23달러에서" → "약 23달러에서"(핀 22.85달러는 레코드 값 그대로).
  3. 같은 문법으로 **나머지 요소 컷**을 만든다: 가이던스 열 확대 인셋 → slope(삼성 부문, C2) → 덤벨 → diverging. 인셋은 머리 줄·캡션 없이 키운 열 + 직접 라벨 + 짧은 이름(D-0328 §3). D-0321 의 항목(출처 줄 밖·속 빈 막대 0→16+띠·리더선)은 이 안에서 흡수. 컷마다 sheet 1장, 네 컷을 한 번에 올려도 된다(판정은 감독이 묶어서 사용자에게).
  4. 그다음 T3 등록(규칙 키·레지스트리·렌더러·프리뷰 세 곳, P10) — 르포 카드 코드·princess 기본값 삭제(P2), `surface: stage` 가 경제 장르 기본.
- 테마는 noturno 토큰으로 간다(사용자가 색을 따로 고르지 않았다 — 구상 프레임이 noturno 였고 승인됐다). navy 는 풀에만.

## 정정(사용자, UF-204) — 손실 막대 = A
- 사용자 원문(2026-10-31): **"A"**. 손실 막대는 **A — 하락색(down)을 바탕과 섞은 채도 낮은 면**(`bars.negative_fill: muted_fill`, `neg_fill_mix 0.45`). 위 "B(잉크 사다리)" 는 취소. 감독의 "응 = B 수용" 해석이 틀렸다.
- 그 밖(방향 승인·noturno·네 컷·T3)은 그대로.
