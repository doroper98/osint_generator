# 결정 요청 — `style.px()` 적용 방식(D-0066 §1 작업 2)

## 1. 쟁점
D-0066 작업 2 는 "픽셀 상수 전부를 `px(n) = round(n × k)` 로 감싸고, layers·render·subtitles·placement 에 픽셀 리터럴 0" 을 요구한다.
저장소 실측과 두 군데서 부딪친다.

1. **리터럴 규모**: 렌더 경로 모듈(layers 11 · cards · fullcards · hud · subtitles · render · panels base/precedent/statement/versus 등)의
   숫자 리터럴(0~3 제외)이 **734개**다. 픽셀 수치·알파·색 성분·시간이 섞여 있다. AST 로 "픽셀인 것"만 가를 수 없다.
   전부 규칙 파일로 옮기면 규칙 키 수백 개가 새로 생긴다. 하나라도 빠뜨리면 1080p 에서 그 요소만 480p 크기로 남는다(조용한 결함).
2. **`round()` 와 MAD 0 의 충돌**: 합격 조건 "k=1 에서 hormuz 25컷 MAD 0" 과 `round(n × k)` 가 맞지 않는다.
   k=1 에서도 `round(10.5) = 10`(카드 태그 글자), `round(9.5) = 10`(출처 글자), `round(1.4) = 1`(날짜 밑줄)로 480p 가 바뀐다.
   k=2.25 에서는 `0.2 × 2.25 = 0.45 → 0`(가는 선이 사라짐), `1.4 → 3`(비율 −5%)이 생긴다. 반올림은 비율을 깨는 쪽이다.

## 2. 선택지

**A. 장치 변환 한 곳(권고)** — 모든 레이어는 지금처럼 **480p 설계 좌표**로 그린다. `render_frame` 이 1920×1080 표면을 만들고
`ctx.scale(k, k)`(k = H/480 = 2.25) 를 **한 번** 건다. 이것이 `px()` 의 전역 적용이다.
- 벡터(글자·선·도형·반경·오프셋)는 cairo 가 장치 해상도로 다시 그린다 → 흐림 없음, 비율은 구조적으로 동일(빠뜨릴 리터럴이 없다).
- 래스터만 장치 해상도로 따로 준비: 지도 베이스(`View.base` 를 장치 크기로, 티어 레벨은 ppd×k — 작업 3), 인물·국기·휘장·사진·컷아웃
  (`Assets.scaled(key, w × k)` 뒤 국소 `scale(1/k)`), 영상 클립(원본 해상도 확인 필요), ffmpeg `-s`.
  이 자리들이 `style.px()`·`OUT.k` 를 쓴다(약 10곳).
- k=1 이면 scale(1)=항등이라 **MAD 0 이 구조적으로 보장**된다.
- 위치 비율 테스트(작업 4)는 설계 좌표가 해상도와 무관하므로 ±0px 로 통과한다. 대신 "렌더 결과"로 증명: 1080p 프레임 Lanczos 축소 MAD.
- 리터럴 테스트 대체: `test_device_space` — 장치 크기(`OUT.width/height/k`)를 읽는 곳은 허용 목록(render·projection·assets·media 래스터)
  뿐이고, 레이어 모듈은 `W_OUT/H_OUT`(설계 854×480)만 본다(AST 검사). 기존 test_no_magic_numbers 대상은 그대로 유지.
- 가로 854 × 2.25 = 1921.5 → 1920: 가로 0.75px 씩 가운데 정렬(오른쪽 날짜 끝이 0.75px 안쪽으로). 비율 차 0.08%.

**B. 지침 문언대로** — 734개 리터럴을 규칙 키로 옮기고 `px()` 로 감싼다. 반올림은 k≠1 에서만(k=1 항등)으로 해야 MAD 0 이 산다.
- 비용: 규칙 파일 대량 증설(사용자 합격 수치를 옮겨 적는 과정의 전사 오류 위험), 레이어 11개 + 패널 전부 수정.
- 누락 1개 = 1080p 에서 그 요소만 작아짐. 검출은 리터럴 테스트뿐(알파·색 성분도 규칙으로 옮겨야 테스트가 통과).

## 3. 권고와 근거
**A.** ① 되돌릴 수 있음: 변환 한 곳 + 래스터 10곳, 되돌리면 원상. ② 13·09 §2 의 목적(모든 픽셀 상수 × k, 레이아웃 동일 비율)을
누락 없이 구조로 달성한다 — "px() 로 감싸는 것"은 수단이다. ③ 15 P3(규칙 SSOT)과 충돌 없음: 480p 기준값은 지금 자리 그대로다.
`round()` 는 A·B 어느 쪽이든 쓰지 않기를 권한다(장치 정수가 필요한 표면 크기·타일 폭만 `round`).
