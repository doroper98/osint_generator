# 결정 — R-0314: 쇼케이스 두 편은 UF-171·172(이란 트랙 사용자 의견) 재발 상태. 공용 장치가 오면 교체본을 만든다

## 선택
1. **교체본을 만든다**(전달본 final/ 은 그대로 두고 `final_v2/`). 사용자가 쇼케이스에 같은 의견을 다시 말하게 두지 않는다 — C12 의 목적은 재발 방지이고, 의견은 이미 원장에 있다(이란 UF-171·172).
2. **장치는 이란 트랙 커밋을 cherry-pick** 한다(규칙 키 종류별 최소 유지 시간 + hard [element-hold]·[media-overlap] + 시험). 쇼케이스가 따로 값을 정하지 않는다(P3 SSOT — 같은 의견에 규칙이 둘이면 안 된다). 이란 감독에게 분리 커밋을 요청했다(2026-11-01 11:25Z). 해시가 오면 내가 보낸다.
3. 그 전에 할 수 있는 것: 연출 수정 **설계만**(렌더 없음) — 24건 각각 "다음 문장까지 연장 / 다른 요소와 자리 바꿈 / 제거" 가운데 하나를 표로. 원칙: 문장 4~5초 구조라 **요소 수를 줄이는 쪽**이 먼저(C0 기준 작품 diesel v2 의 밀도는 요소 수가 아니라 카메라·데이터 패널에서 온다), 한 장면에 사진 둘을 넣어 둘 다 짧게 하지 않는다. niovi 클립 ↔ art_0020 은 기사 카드를 클립 뒤 문장으로 옮긴다.
4. 장치 cherry-pick 뒤: 설계 적용 → 프리뷰 hard 0(새 hard 둘 포함) → 콘티 판 재렌더(`require_animatic` — 연출이 바뀌면 콘티 판도 다시, 우회 없음) → 게이트 ② 는 **감독이 사용자에게 교체본 사유와 함께 묻는다**(연출 변경이 사용자 의견 적용이지만 24건이라 재승인) → 전편 → `final_v2/` + R.

## 근거
- 판정 기준 ③: 사용자 의견은 트랙을 가리지 않는다(C12-3). 실측이 재발을 보여 준다(사진 최소 0.91초는 의견과 무관하게 결함).
- 판정 기준 ①: 전달본은 지우지 않는다. 교체본은 폴더 추가.
- 규칙 값은 한 곳(이란 커밋)에서만 정한다 — 두 트랙이 같은 날 같은 키를 다르게 만드는 것을 막는다.
