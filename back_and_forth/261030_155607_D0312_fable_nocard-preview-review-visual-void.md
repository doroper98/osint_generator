# 판정 — 카드 없는 프리뷰 2편(artifacts 181a738) 사용자 전달. 카드가 빠진 자리가 **빈 화면**으로 남았다 → `[scene-visual-void]` hard + 빈 자리 채우기. 템플릿 표시 줄은 아직 안 보인다

## §0 눈 확인(감독)
- geo 16컷: 구석 카드 0, 사진은 가운데 큰 자리(04 모스크바 정유소 화재, 08 구축함 수병) — 좋다. 0~12초 타일: 랴잔 인셋이 왼쪽에 한 번 자리 잡고 안 움직인다, 표적 라벨과 안 겹친다(D-0305 ①② 통과).
- **결함 A — 빈 화면**: geo 12컷(194.4초 "미국은 지난해 러시아 석유회사들을 제재한 나라입니다")·13컷(206.4초)이 지도 + 자막뿐이다. 옛 card 가 있던 자리를 지우기만 하고 대체 요소를 넣지 않았다(D-0306 §1-3 "버린다" 의 부작용). econ 에도 같은 유형이 있는지 점검(02·08·09 는 차트가 있어 괜찮다).
- **결함 B — 템플릿 표시 줄(UF-147)**: 타이틀 부제("쇼케이스 템플릿 · 지경학/경제")도, 엔딩 카드 줄도 아직 없다(econ 엔딩 컷 181.5초 확인).
- econ 12컷: 카드 4개 제거 외 변화 없음, hard 0.

## §1 결정
1. **`[scene-visual-void]` hard**: 지도·배경만 보이는 구간(마커·사진·기사·인용·패널·아일랜드·클립·인셋·뱃지 중 하나도 안 보이는 시간)이 `qa_checks.visual_void_max_sec`(제안 5초) 이상이면 실패. 콜드 오픈·타이틀·엔딩·전환 이동 중은 제외. provenance 에 빈 구간 목록.
2. **빈 자리 채우기(geo 12·13컷 + 점검 결과)**: 사실에 맞는 요소로 — 12컷(OFAC 제재): 재무부 OFAC 보도자료 기사 카드(article, 등재본) 또는 제재 대상 로스네프트·루코일 **마커 + 핀 라벨**(지도 위 본사 위치, 출처); 13컷: 그 문장이 말하는 대상의 사진/기사. 새 자산은 레지스트리 등재·권리 기록. 연출은 `revise_direction` 로(코드가 끼워 넣지 않는다, P8).
3. **템플릿 표시 줄 지금**: description.yaml 부제에 "쇼케이스 템플릿 · 지경학"/"· 경제" 를 넣어 타이틀 카드에, 엔딩 카드 머리 줄 오른쪽에 같은 글자 — `template_label` 키 merge 전이라도 description 경로로. merge 뒤 키로 옮긴다.
4. 그 뒤 **게이트 ② 자료**(프리뷰 시트 2편 재생성·A/B 시트·카탈로그 표·미디어 요약·표시 줄 컷) → artifacts → R. 사용자에게는 감독이 보낸다.
