# G4 연출 보강 — G3 데모 시트 육안 판정에서 나온 지적(C0 영상미, D-0090 작업 4 에 합쳐 적용)

G3 데모는 공학 증명으로는 합격이다. 영상미로는 "움직이는 대시보드" 에 가깝다. G4 본편은 아래를 지킨다. 규칙 수치는 `rules stage_timeline`·`style` 토큰으로만 두고(리터럴 0), 골든·데모 회귀는 무변경.

1. **휑한 화면 금지(20 §6 LOD 문단)**: 12컷 중 8컷이 얇은 선 두 개와 빈 "기록" 레인이다. 본편은 컷마다 무대 외 요소가 최소 하나(핀 카드·뱃지·기사 카드·statement_diff·dot_plot) — checks 의 `media_beats`(40~60초당 1) 를 warning 으로 두지 말고 본편에서는 hard 0 을 목표로 한다(검사 등급은 바꾸지 않는다, 결과로 증명).
2. **색 의미를 선에 입힌다**: 목표 범위 띠·실효금리 계단의 상승 구간 = `color_semantics.hike`, 하락 = `cut`, 동결 = `hold`(20 §3). 지금은 한 색이다. 구간 색은 레코드 값 변화에서 코드가 정한다(연출이 색을 적지 않음).
3. **글자 크기**: 레인 라벨·출처·기준 시점 줄이 glyph_size 는 통과하지만 시트에서 읽기 어렵다. 레인 라벨 역할을 `layout_480p` 의 카드 제목급으로 올릴지 rules 토큰 값으로 제안하라(사용자 합격 값 변경이므로 **decision_request** 로 값·근거·비교 컷 2장). 골든은 시간축 무대가 없으니 영향 없음.
4. **카메라**: 같은 핀에 두 숏(05·06 = 2022.06) 처럼 머무는 구간을 줄이고, 핀 확대 시 카드가 함께 등장(핀 = 사건 + 근거 카드). 왼쪽→오른쪽 이동 중에 계단이 자라는 구간에서는 값 라벨이 앞끝을 따라간다(지금은 끝점만).
5. **콜드 오픈**: 제목 카드 뒤 첫 컷이 "전체 시간축 조망" 인데 정보가 없다. 20 §10 구조대로 최근 회의 핀 확대 + 의장 뱃지 + 성명서 인용으로 연다.
6. **미디어 비트**: 기자회견 사진(권리 확인된 것만)·기사 카드·공식 게시물 카드를 40~60초당 1개. 없으면 그 구간은 patch 가 아니라 statement_diff·dot_plot 으로 채운다.
7. **엔딩 카드**: 자료 줄이 두 줄뿐이라 카드가 비어 보인다. 본편은 출처(보도·공식 발표·시리즈)가 늘어나므로 자연히 채워진다 — 카드 레이아웃은 바꾸지 않는다.

이 지적은 게이트 ② 1차 판정 기준에 포함한다(루브릭 §9 + 위 1·2·4·5).
