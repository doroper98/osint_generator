# 결정 — econ 콘티 판 v2: 카드는 A(제거), 점도표는 틀 안 슬롯으로, `[card-over-panel]` 을 시간축 틀로 확장

감독 실측: v2_candidate `cards_over_frame.png`·`sheet_13s.jpg`·프레임 — 카드 3장과 점도표 자리표시가 틀 오른쪽 테두리를 넘어 축 값(5.5%·0%)을 덮는다. 틀이 생기자 보이게 된 결함이고, UF-129("그래프를 가리지 않도록")의 미보호 경로가 맞다.

## 선택
1. **카드 3장(act1_4·act2_6·ending_0)은 A — 연출에서 제거**(손 수정, D-0248 선례). 내용은 핀 라벨·자막에 이미 있다. 네 번째 카드도 틀 테두리를 넘으면 같이 뺀다. 카탈로그 요소 "card" 는 geo 편(카드 70여 장)이 보여 준다 — econ 에서 빠져도 쇼케이스 목적에 결함이 없다. 미포함 사유에 "시간축 틀 안 카드 자리 없음(E 후속)" 한 줄.
2. **점도표(act3_1)는 남긴다 — 틀 안 슬롯으로.** `rules placement` 에 시간축 무대 전용 프리미티브 슬롯 하나(예: `timeline_primitive: {kinds: [primitive], box: [...], stages: [timeline]}`) — 상자가 틀 `[60,60,734,330]` 안에 완전히 들어가고 날짜 눈금 줄 위에서 끝난다. 값은 제안 → 같은 R 에 한 줄로 올리면 즉시 결정(렌더 전 값 하나 결정이라 decision_request 형식 생략 가능 — 이 D 가 사전 승인: **틀 안에 완전히 들어가고 오른쪽 끝이 축 값 열 왼쪽에서 끝나면 어떤 값이든 승인**). 점도표는 핀 확대 안에서 자란다(§6.1).
3. **장치 보강(UF-129 미보호 경로, C12-3)**: `[card-over-panel]` 이 시간축 주 무대에서는 **틀 안 시리즈 레인 상자**(레코드가 있는 레인)를 데이터 패널로 센다 — 덮개(card·primitive·photo·clip·cutout·badge)가 시리즈 레인 상자와 교차하면 hard. 사건 레인은 허용. 틀 테두리를 넘는 덮개는 `[chart-edge-bleed]` 가 잡도록 덮개 상자도 검사 대상에 넣는다. 테스트 2건(레인 교차 hard·사건 레인 허용). 원장 UF-129 guards 에 보강 장치 추가(칸 보강만). 한 커밋.
4. 순서: 3(장치) → 1·2(연출 수정, 검사 hard 0) → `render --animatic` → artifacts `showcase_econ/animatic.mp4` 교체(v1 보존, v2_candidate 삭제, MD5SUMS) → R + send_message. 감독이 사용자에게 보낸다. **v2_candidate 는 사용자에게 보내지 않는다**(콘티 판의 카드·패널은 전편과 같아야 한다 — PIPELINE-AP-018).

## 근거
- 판정 ①(연출 수정은 되돌리기 쉬움, 점도표 슬롯은 값 한 줄) ③(저장소 규칙 UF-129·AP-018 우선). B(카드 열 예약으로 시간 폭 출렁임)는 "하나의 연속 세계"(C0·UF-135)와 어긋나 기각.
- 틀 안 카드 자리(핀에 붙는 카드, C0 "핀 = 사건 + 근거")는 쇼케이스 뒤 E 후속으로 설계한다 — 사건 레인 높이와 카드 높이 관계가 수치 결정을 요구한다. 지금 하지 않는다.
