# 2D→3D 이음새 ≤ 2px(D-0143 §4) — 검토본 기하로는 불가, 선택 요청

## 쟁점

D-0143 §4 는 "첫 3D 프레임의 지상 궤적 양 끝 화면 좌표가 2D 마지막 프레임과 ≤ 2px(설계 px)" 를 테스트로 요구합니다.
검토본(4d9dc65 globe3d.py) 기하를 그대로 옮기면 **최대 11.7px** 어긋납니다. 원인은 둘입니다.

## 실측(설계 px, 2D = handoff 41.0 + 2.0×0.3 = 41.6초 프레임, 3D = t_2d 첫 프레임 k = 80)

| 끝점 | 2D (x, y) | 3D 검토본 (x, y) | 차 |
|---|---|---|---|
| 발사점(평양 순안) | (105.72, 303.58) | (94.63, 291.84) | 11.1, **11.7** |
| 착탄점 | (602.47, 170.49) | (602.64, 165.83) | 0.2, 4.7 |

원인 분석:
1. **줌 차이(고칠 수 있음)**: 3D 시작 카메라 폭 = 마지막 숏 w × (1 − push_in) = 18.82°. 실제 2D 카메라는 41.6초에 푸시인이 진행 중이라 19.22°(2.1 % 차).
   2D 카메라의 그 시각 w 로 3D 시작 높이를 정하면 가로 차가 11.1 → 4.2px 로 준다.
2. **투영 차이(기하 본질)**: 2D 는 메르카토르, k = 80 구는 방위 등거리(접점 중심)입니다. 접점에서 7° 서쪽인 발사점은 방위 등거리에서 위선이 위로 휘어 세로로 **약 12.8px** 위에 놓입니다.
   줌을 맞춰도 남습니다(아래 B 실측 12.8px). k 를 아무리 키워도 평면 극한이 메르카토르가 아니라 방위 등거리라 없어지지 않습니다.

## 선택지

**A. 검토본 기하 유지 + 이음새 측정·기록(권고)**
- 현재 이식 그대로(사용자 검토본과 3D 7컷 중 4컷 픽셀 동일, 나머지 3컷은 결함 수정 2건만 차이).
- 테스트는 "이음새 실측값 ≤ 검토본 실측(11.7) + 0.5px" 로 **회귀 방지**만 하고, run_log 에 값과 원인을 적는다.
- 교차 전환 1초 동안 두 궤적선이 최대 약 12px 떨어져 겹쳐 보인다(검토본에서 사용자가 이미 본 화면).
- 되돌리기: 테스트 임계 한 줄.

**B. 3D 시작 줌만 2D 카메라에 맞춤**
- 가로 오차 11.1 → 4.2px. 세로 12.8px 는 남음. 7컷 중 t = 4.5·6.5 컷이 미세하게 달라진다(검토본 대비 화면 변경).
- 테스트 ≤ 2px 여전히 불통 → 임계를 13px 로.

**C. 곡률 전환 시작을 메르카토르 평면에서 출발**
- 국소 좌표를 "메르카토르 평면 좌표 → kR 구" 로 k 에 따라 섞는다(to_local·래스터 역사상 둘 다). ≤ 2px 달성 가능.
- 비용: globe 기하·래스터 역함수 재설계(래스터는 화소마다 역사상을 섞어야 함), 검토본과 3D 전 구간 화면이 달라짐 → 사용자 재검토 필요. 이 트랙 범위(검토본 이식)를 넘는다.

## Opus 권고

**A**. 판정 기준 ① 되돌리기 쉬움, ② D-0140 §7 "사용자가 본 값 그대로" 와 D-0143 "그 외 수치는 검토본 그대로". ≤ 2px 은 실측 전 목표치로 보입니다(렌더 시간 60초 → 180초 정정과 같은 성격).
C 는 본편 globe 무대 등록(트랙 밖, S4 후보 목록) 때 다룰 과제로 기록하기를 권합니다.

## 막히는 범위

- 막힘: 이음새 테스트의 임계값 한 줄.
- 계속 진행: 나머지 S2 전부(globe·globe_scene·CrossfadeScene·SK-C1(3D)·SK-H6·테스트·전편 렌더·삭제·보고). 이음새 테스트는 측정만 하고 임계는 결정 뒤 넣는다.
