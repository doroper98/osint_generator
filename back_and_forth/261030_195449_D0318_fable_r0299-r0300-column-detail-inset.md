# 판정 — 덤벨(R-0299)·diverging(R-0300) 스케치: 문법 맞음, 그러나 분기 열 폭(420일 축 안 1분기 ≈ 1/5)에 갇혀 **너무 작다**. 축척은 못 바꾼다(UF-138) → 같은 값을 크게 보여 주는 "열 확대 인셋" 으로 다시 그린다

## §0 눈 확인
- 덤벨: 속빈→채움 원·지시선 라벨·accent 1·감소 흐림 — 규칙대로. diverging: 0 기준 위아래·코드 계산 y/y·단위 % 레인 — 규칙대로. 둘 다 hard 0(정직성 2건은 T3).
- 결함: 요소가 분기 열 하나에 몰려 점 반지름·글자가 480p 에서 읽히는 하한 근처다. 왼쪽은 빈다(본편에선 추이 층이 있으니 비는 건 문제 아님). 지시선 라벨이 오른쪽 축 열에 잘린다.

## §1 결정 — 열 확대 인셋(`island` 의 `kind: column_detail`, 지도의 위성 인셋과 같은 역할)
1. 시간축 아일랜드 안의 **그 분기 열**을 리더선으로 가리키는 **확대 인셋**(둥근 사각, 아일랜드 안 빈 쪽에 자동 배치 — 인셋 side_order·안전 영역·라벨 장애물 규칙 재사용, D-0300·D-0305). 인셋 안에 덤벨·diverging·bullet·slope 를 **크게** 그린다(글자 ≥ 12px, 점 반지름 ≥ 5px). 머리 줄 "2026년 3분기 · 부문 매출(십억 달러)". **같은 값, 같은 레코드, 같은 시점** — 다른 시간축이 아니라 한 열의 확대다(UF-135 위반 아님, 지도 인셋과 같은 지위). 아일랜드의 해당 열은 accent 띠로 강조.
2. 등장: 그 층을 말하는 문장에서 열에서 자라나듯(슬라이드+페이드 0.4~0.6초), 끝나면 페이드. 카메라는 그 열로 이동(문장마다 카메라).
3. 범위: dumbbell·diverging·slope 는 **인셋 전용**(열 안 직접 그리기 폐기). bullet 은 열 안(막대와 같은 자리)이 맞으니 그대로. 가이던스 속빈 범위도 열 안.
4. 라벨 잘림: 인셋 안에 두므로 축 열 잘림 사라짐. `[inset-clipped]` 그대로 적용.
5. 린트(R-0300 §2): 분기 레코드 대조 — 문장 date 의 달을 분기로 접어 분기 말 레코드와 맞추고(`quarter_of(date)`), 코드 계산 값(y/y·q/q·차이 %)은 **파생 레코드**로 등록(`derived: {op: yoy_pct, from: [A, B]}`, formula 는 rules data.transforms 에)해 린트가 같은 수로 대조. 이게 돼야 "78%" 를 원고가 말할 수 있다 — T3 에 포함.
6. 산출: 덤벨·diverging **인셋 판** 각 1컷(같은 시각) → artifacts → R → 감독이 사용자에게 요소 ⑥⑦ 승인 질문. 그다음 slope(인셋)·가이던스.
