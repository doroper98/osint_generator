# 사용자 의견 UF-127 — 조사 '가'가 [까]로 경음화("경유까", "제트유까"). 발음 사전으로 고치고 재발 방지 장치, 지금 도는 렌더는 버린다

사용자(교체본 final_v2_r2 시청, 스크린샷 2장): **"조사로서 -가 가 붙었는데 경유까, 제트유까 하고 발음 함. 재발 방지 해"**
(`rules/user_feedback.yaml` UF-127, 수신 즉시 기록·status open).

## 0. 원인(감독 실측)
- 해당 문장(v2 원고, tts 명시 없음 — text 그대로 합성):
  - `act2_35` 「정유소가 모자란 극동의 빈자리에, 한국 항구에서 실린 **경유가** 들어간 셈입니다.」
  - `act3_15` 「한편 청와대 국가안보실은 무역통계상 한국에서 러시아로 경유와 휘발유, **제트유가** 수출된 기록은 없다고 밝혔습니다.」
- 원고 전체에서 `(경유|휘발유|제트유|중유|등유|원유|석유|정제유|항공유|연료유|벙커유|윤활유)가` 꼴은 이 2건뿐(감독 grep).
- 원리(추정, 엔진으로 확인할 것): Supertonic 의 G2P 가 '…유' + '가' 를 낱말 **유가(油價, [유까])** 로 묶어 경음화한다. "정유소가"(act2_35 앞부분)는 '소가' 라 멀쩡하다. 같은 부류 TTS-AP-067·068(발음 사전 구조 조치), TTS-AP-080(사전으로 붙이기)의 반대 방향 — **사전으로 떼어 읽히기**.
- 콘티 판·전편 QA 가 못 잡은 이유: 발음 린트(`tts_risk.spoken_patterns`)에 '명사 끝 유 + 조사 가' 패턴이 없다. 청취 판정은 사용자만 한다(C0.2).

## 1. 그 영상 먼저(C12 §2)
1. **지금 도는 720p 렌더(D-0245 그래프 복원)는 중단하고 버린다.** 음성이 바뀌면 타임라인이 바뀌어 어차피 다시 렌더한다. artifacts 는 손대지 않는다.
2. **발음 사전 경로로 고친다(원고 `script.yaml` 불변 → 원고 지문 불변 → 게이트 ① 재승인 불필요).** `script.lint.pronounce_tts` 가 합성 직전에 거치는 발음 사전(`load_pronounce_dict`)에 항목을 넣되, **손으로 2건을 넣지 않는다** — 규칙 파일에 명사 목록을 두고 사전 항목을 거기서 생성한다(§2). 쓰기 형태는 엔진으로 실측해 고른다: 후보 "경유 가"(띄움), 필요하면 다른 분절. 판정은 (a) 합성 파형을 들을 수 없으니 **같은 문장을 '유가'(油價) 낱말이 들어간 대조 문장과 함께 합성해 wav 를 R 에 첨부**(청취 자료는 첨부만, C0.2), (b) 띄운 형태가 문장 안에서 쉼을 만들지 않는지 MMS 정렬의 '유'~'가' 간격(ms)을 원문 합성과 비교해 표로 적는다. 간격이 비정상(> 120ms)이면 다른 분절을 시도한다.
3. 두 문장 재합성(캐시 키가 바뀌므로 자동) → 정렬 → `python -m audio.mix` → 프리뷰 checks hard 0 → **콘티 판 재렌더(의무, `require_animatic` 는 현재 음성 타임라인의 기록을 요구하고 우회 플래그가 없다; 검토 왕복은 없다 — D250)** → 게이트 ② 재기록(D-0243 위임) → 720p → QA → artifacts 덮어쓰기(README "v2 교체 2: 그래프 복원(UF-126) + 발음 '유가' 경음화 수정(UF-127)") → 증거 컷(그래프 3장 + 두 문장 구간 프레임) + **두 문장 음성 wav 2개**(사용자 청취용) → R + send_message 한 줄. 감독이 사용자에게 보낸다.

## 2. 장치(C12 §2·§3 — 영상 전달 뒤 첫 작업, D-0245 §2 장치와 함께)
- `rules/video_rules.yaml tts_rules.tensification_traps`(새 키): `{suffix_nouns: [경유, 휘발유, 제트유, 등유, 중유, 원유, 석유, 정제유, 항공유, 벙커유, 윤활유, 연료유], particles: [가], spoken: "{noun} {particle}"}` 처럼 **구조 필드**. 발음 사전은 이 키에서 생성(모든 영상, 합성 직전, 코드 상수 금지 P3). 목록은 '유(油)' 로 끝나는 기름 명사에 한정한다 — '이유가·자유가·사유가' 는 건드리지 않는다(과잉 치환 금지, TTS-AP-075 교훈).
- 린트 `tts-tensification`(`script.lint`, 게이트 ① 린트에 포함) **hard**: 발음 텍스트(명시 tts 또는 text)에 목록 명사 + 조사 가 가 붙어 있는데 사전 적용 결과가 그대로면 실패. 사전이 적용되면 통과(= 장치가 실제로 효력을 갖는지 검증).
- 테스트: (a) 두 문장으로 `pronounce_tts` 결과가 "경유 가"·"제트유 가" 가 되는지, (b) "이유가 있다" 는 불변, (c) 사전 항목이 규칙 키에서 생성되는지(규칙에 명사를 더하면 항목이 늘어남), (d) 린트가 사전 없이는 hard, 사전이 있으면 0.
- `docs/ANTIPATTERNS/TTS_ANTIPATTERNS.md` TTS-AP-083 append(증상·원리·원칙 "기름 명사 + 가 는 사전으로 띄어 읽힌다"·자동 조치·발견 버전 v7.4.0). UF-127 `guards` 에 린트·규칙 키·테스트를 달고 guarded. DECISIONS 한 줄.
- 엔진 실측에서 띄움이 쉼을 만들어 못 쓰고 다른 분절도 안 되면: 문장을 바꾸지 말고 R 에 실측 표를 적고 감독에게 결정 요청(원고 수정은 사용자 재승인 사안).
