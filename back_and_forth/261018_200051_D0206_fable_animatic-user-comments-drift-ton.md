# 사용자 콘티 판 의견 5건 반영 — 엔진 3건 + 연출 + 원고 1문장. 반영 뒤 **콘티 판 재렌더(본 지도)** → 감독 게이트 ② 재판정 → 전편

원문은 `rules/user_feedback.yaml` UF-120~124(정본). D-0240 의 필수 5건은 그대로 유효하다.

## 1. 정지 카메라 금지 + 느린 훑기(UF-120) — 모든 영상 공통 규칙
- `rules camera.static_max_sec: 20`. 검사 `[static-camera]` **hard**: 어떤 20초 창에서도 카메라(center·w)가 변하지 않고(변화 < `static_eps`: w 1%·center 0.5% w) 새 화면 요소(카드·사진·경로 grow·패널·인셋·뱃지 등장) 도 없으면 실패. 콘티·프리뷰·전편 같은 검사.
- 새 카메라 이동 종류 **`drift`**(궤도 훑기): `{type: drift, from: {lon,lat,w}, to: {lon,lat,w}, start, end}` — 시작~끝을 문장 경계와 무관하게 **등속·아주 느리게**(기본 속도 상한 `camera.drift_speed_max`: 화면 폭의 2%/초, w 변화 1%/초) 이동. 쇼트 문법의 "문장마다 카메라 이동" 과는 별개의 바탕 움직임이고, 그 위에 카드·마커가 얹힌다. C0 "문장마다 카메라 이동, 줌이 튀어 오르는 연출 금지" 와 충돌하지 않는다(튀지 않고 느리다). `camera_suggest` 가 정지 구간을 찾아 drift 를 제안한다(연출이 채택).
- 대안: `backdrop` 사진(권리 통과) 위 카드 — 사진이 있을 때만.
- 이번 영상 적용: ① 55~100초(1막 IEA 설명) — 러시아 서부 w 36 에서 볼가강 따라 사라토프→랴잔 방향 drift 60초 ② 420~585초(3막 서울) — 한반도 남부(부산·울산)에서 동해를 따라 블라디보스토크까지 drift 150초(사용자 제안 그대로) ③ 770~890초(5막 워싱턴) — 미국 동부 w 30 에서 워싱턴 근접 w 8 로 drift 110초, 그 위 기사 카드·뱃지. 다른 정지 구간도 검사로 잡히면 같은 방식.
- 테스트: `tests/test_v740_static_camera.py` — 정지 25초 fixture hard, drift 넣으면 통과, 카드 등장만으로도 통과(요소 변화), 골든 무변화(골든은 문장마다 이동이라 정지 20초 없음 — 실측해서 R 에).

## 2. 콘티 판 = 본 지도(UF-121, UF-106 재발) — D-0108 폐기
- `engine.render --animatic` 이 FlatMercatorStage 대신 **본 MercatorStage**(지형·행정선·도시·도로·강·테마)로 480p 렌더. 막지도 코드는 삭제(P2). 콘티 전용 표시(워터마크 "콘티")는 유지.
- 렌더 시간이 늘면 R 에 실측(콘티 976초 기준).
- AP: `docs/ANTIPATTERNS/RENDER_ANTIPATTERNS.md` 새 번호 — "콘티 판 막지도가 사용자 판단을 왜곡(UF-106→121 재발)".

## 3. 단위 ton(UF-122, UF-111 재발)
- `rules data.units` 표기: `t` → 화면 `ton`(카드 bigs·lines·패널 값·축·마커 부제·인셋 캡션 전부). 내레이션 발음 텍스트는 "톤" 그대로(이미 그렇다면 무변경). 숫자 뒤 "만 ton" 처럼 띄어쓰기 유지.
- 검사 `[unit-ton-glyph]` hard: 화면 문자열(연출 텍스트)에 `\d\s?t(\b|$)` 가 남으면 실패. UF-111 의 단위 글꼴 분리는 다른 라틴 단위(kb/d·mb/d·bbl)에 그대로.
- AP: `docs/ANTIPATTERNS/RENDER_ANTIPATTERNS.md` — "글꼴 교체로 사용자 지적(십자형 t)을 해소하려 했으나 기준은 표기였다(UF-111→122)".

## 4. 항로 속도(UF-123)
- `rules route.grow_speed_max_px_s: 45`(설계 px/초). route grow 시간 하한 = 길이/속도; `declared` 굴절 항로는 꺾임 앞 점선·뒤 실선 각각 적용(실선이 더 느려도 된다). 검사 `[route-too-fast]` hard. 레일라(두 번째)·아스토리아·청천 항로 grow 재조정 — 문장 길이가 모자라면 다음 문장까지 end 를 늘린다.
- 테스트: grow 가 하한보다 짧은 fixture hard.

## 5. 원고 act3_8(UF-124) — 1문장, 롤백 경로로 재승인
- "즉 이 제도에서 제재 대상은 러시아가 파는 석유이고, 러시아가 사들이는 연료는 비제재 대상입니다."
- `banned_phrases` 에 제도·법·규정 주어의 "겨누는|겨누지|겨냥하는|노리는" 추가(발언 인용 안은 제외). 전편 원고 전수 재린트.
- rollback(사유 "사용자 어휘 지적 UF-124") → 재린트 → 사용자 재승인(감독이 요청 중) 기록 → 해당 문장만 재합성(나머지 md5 동일 기록).

## 6. 순서
D-0240 필수 5건 + 위 1~5 → 콘티 판 재렌더(본 지도, 480p) → artifacts animatic v2.1 푸시 → R(시트·추출 컷: drift 3구간 시작/중간/끝 컷, ton 카드, 항로 grow 시간표, 본 지도 근접 숏) → 감독 게이트 ② 재판정 → 전편.
- 콘티 R 전까지 사용자 재승인이 안 오면 콘티는 그대로 렌더하되(음성 1문장 재합성 포함) 승인 기록만 뒤로 미룬다(게이트 ② 전 필수).
