# T2 스케치 ① 막대(series bars) — 사용자 승인 요청용 · T1 보완 둘

## 1. 스케치(artifacts 브랜치 `artifacts/econ-template-2026` 0af5d5d9, 폴더 `t2_bars/`)
- 실제 엔진 렌더 8컷 + 시트(`frames/sheet.jpg`), 미등록 패치 `bars_sketch.patch`(76줄, 4파일), 스케치 프로젝트 원고·연출.
- 데이터: `INTC_REV_Q` 막대(5분기, 8-K) + `INTC_PX_D` 선(9/1~) — 같은 시간축 두 레인. w 400 고정·날짜 이동만(UF-138).
- 막대 문법: 분기 열 가운데, 폭 = 분기 × 0.55, 0 에서 자란다(시간축 앞끝이 지나는 동안). 막대마다 값 라벨(레코드 값 그대로). 레인 범위가 0 을 품는다.
- 사용자에게 보낼 컷: `frames/p_0019.38.png`(3분기 막대가 자라는 중), `frames/p_0036.39.png`(막대 레인 + 주가 레인 + 발표일 핀).
- 승인되면 T3 에서 등록한다(레지스트리·SeriesEvent.style·렌더러·프리뷰 예제·[bars-from-zero]·시험 한 커밋). 지금 브랜치에는 렌더러를 넣지 않았다.

## 2. 스케치가 드러낸 것 — T3 설계 입력
- 0 기준 막대는 값(13.6~16.5)이 레인 위쪽에 몰린다. 그래서 `[axis-empty-band]`(아래 빈 띠 68 %)·`[flat-lane]` 이 hard 로 걸린다.
  막대 레인은 0 이 정직성 기준이라 이 둘에 막대 레인 예외가 필요하다. T3 에서 `[bars-from-zero]` 와 같은 커밋으로 넣겠다(되돌리기: 예외 줄 삭제).
- 막대끼리 높이 차이가 작게 보인다. 0 기준이면 정상이다. 차이는 다음 스케치(예상치 표식·차이 라벨)가 말한다.
- 인텔 부문 합 ≠ 전사 매출(파운드리 내부 거래) — 쌓임 스케치에서 "합 = 전사" 검사를 어떻게 둘지 결정이 필요하다(쌓임 스케치 때 decision_request).
- `[plot-height]`·`[chart-only-run]`·`[media-density]` 도 걸렸다. 영상 문법 검사이고, 실적 영상은 사진 배경 + 차트 아일랜드(D-0304)라 본편에서 채운다.

## 3. T1 보완(ca5ace67) — 스케치 렌더에서 드러난 결함 둘
- 공백 있는 단위("십억 달러"·"조 원")를 정직성 검사가 첫 낱말만 봐서 `[unit-missing]`·`[unit-mismatch]` 로 오판했다. 등록 단위 중 가장 긴 머리로 판정하게 고쳤다.
- series 선 구간 나누기가 월 간격만 알아서 일별 종가가 점마다 끊겨 선이 사라졌다. daily·quarterly 는 missing 날짜에서만 끊게 고쳤다(월별은 종전 그대로).
