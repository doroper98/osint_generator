# 결정 — OFAC 문서(src_doc_0002·0003)는 문서 카드를 새로 만들지 않고 **지도 마커 + 핀 라벨(출처 줄)** 로. 빈 구간 6개는 revise_direction 결과를 감독이 본다

1. **문서 카드 신설 안 함**(20 §4.3 새 요소 상한·스케치 승인 절차 — 지금 쇼케이스 마감 단계에 새 요소를 넣지 않는다). OFAC 제재 두 건은 **마커**로: 로스네프트·루코일 본사(모스크바, 지명 사전 좌표) 마커 + 두 단 핀 라벨("로스네프트·루코일 제재 · 2025. 10. 22" / "미 재무부 OFAC") + 레인 아래 출처 줄은 기존 marker 출처 표기 규칙대로. GL135(src_doc_0002)는 같은 핀의 둘째 줄 또는 다음 문장 핀. 재무부 청사 PD 사진이 Commons 에 있으면 가운데 큰 사진 한 컷(권리 등재).
2. 문서 카드(공시·보도자료·판결문 조판)는 **후속 요소 후보**로 `docs/handoff/DECISIONS` 한 줄만 — 경제 템플릿(8-K·DART 표)에서 쓰임새가 생기면 그때 스케치·승인(E4 절차).
3. 빈 구간 6개(23.1~·45.8~·69.9~·85.1~·116.0~·191.1~206.7): 워커 결과를 **프리뷰 시트로** 감독이 본다 — 채운 요소가 문장 내용과 맞는지(사실 일치), 되풀이 글자 0, 밀도 상한(media.density) 안인지. 못 채운 구간은 R 에 사유.
4. 템플릿 표시 줄을 연출 키 `template_label` 로 넣은 것 승인(장르 값보다 앞, 골든 불변). 엔딩 라이선스 줄바꿈 1f4ccdc1 승인.
5. 다음: 프리뷰 시트 2편 재생성(빈 화면 0·표시 줄) → 게이트 ② 자료 일체 → artifacts → R.
