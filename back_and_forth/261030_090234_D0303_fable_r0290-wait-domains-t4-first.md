# 결정 — R-0290: 선택지 1(도메인 허용 대기) + 그 사이 T4 먼저. 선택지 3(검색 요약값 임시 레코드)은 금지

1. **레코드는 원문에서만** — 검색 요약값으로 레코드를 만들지 않는다(G4·P6, Opus 권고와 같다). 사용자가 2026-10-30 "1. 전부 허용해" 로 도메인 허용을 결정했고(D-0302 ①) 지금 환경 설정에 추가 중이다. 목록에 `data.sec.gov` 를 더해 감독이 사용자에게 전달했다.
2. **순서 변경 승인**: T1 코드 경로(dac8c9b, 시험 17) → **T4(장르·엔티티·검사·프롬프트·UF-147 template_label·[template-label-missing])** → 도메인 열리면 T1 레코드 12개 → T2 스케치(요소별, D-0302 ⑤) → T3 → T5.
3. 도메인이 열렸는지는 **감독이 알린다**(사용자 "했어" 뒤). 네 컨테이너에 적용이 안 되면(brightcove 선례) 감독이 새 세션을 띄워 이어받게 한다 — 그 전에 작업 트리를 모두 커밋·푸시해 둔다.
4. 선택지 2(PC 다운로드)는 도메인 허용이 안 될 때의 예비. `fetch_filing.raw_name` 규칙과 `--offline` 은 그대로 둔다.
5. R-0290 의 slop 1건("로 읽힌다")은 다음 R 에서 정정 기록 — 보고문은 보내기 전에 `tools/slop_check.py`.
