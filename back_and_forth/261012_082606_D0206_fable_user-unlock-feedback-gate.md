# 사용자 결정 — 의견 원장 게이트 "잠금 풀어"(감독 기록)

사용자 원문(2026-10-12): **"잠금 풀어"** — 감독이 "검사 없는 의견이 있으면 본영상 렌더가 잠긴다, 이번엔 작은 검사 2개를 먼저 붙인다"고 설명한 직후. 앞선 사용자 지시 "영상 먼저 보완하고 보내줘. 그 뒤에 규칙을 가다듬어"와 같은 방향.

## 해석(감독)
- **기록 의무는 그대로**(C12-1, "모두 기록되고 재발이 되면 안 돼"). 의견은 받는 즉시 원장에 적는다.
- **잠금만 푼다**: 장치 없는(open) 의견이 있어도 `preview_approval` 을 거부하지 않는다. 대신 ① 승인 화면·provenance·R 보고에 open UF 목록을 경고로 띄우고 ② 그 영상을 사용자에게 보낸 뒤 **다음 작업 첫 순서로** 장치를 붙여 guarded 로 만든다(재발 방지 의무는 유지, 시점만 영상 뒤로).
- 지금 진행 중인 gulf v6.0.2 렌더는 UF-97·98 이 이미 guarded 라 영향 없음 — **렌더를 멈추지 않는다.**

## 지시(gulf v6.0.2 전달 뒤, 규칙 정리 2단계와 함께)
1. `require_feedback_guards` 차단 → 경고로(우회 플래그가 아니라 규칙 자체 변경). 경고 문구에 UF 번호·원문.
2. CLAUDE.md C12-2 문구 개정: "장치 없는 의견 = 게이트 차단" → "장치 없는 의견 = 경고 + 영상 전달 뒤 첫 작업으로 장치(사용자 결정 D217)". `test_user_feedback_guards` 는 open 허용하되 open 이 남은 채 **두 번째 영상**의 게이트를 지나면 실패하도록(기한 장치) — 방법은 제안.
3. DECISIONS D217.
