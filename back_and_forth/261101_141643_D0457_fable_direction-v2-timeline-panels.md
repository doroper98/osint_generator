# 연출 v2(a6d6e22f) 선검토 — 콘티 판 렌더 전에 고칠 것 둘: 시간축 패널 지속 범위, 데이터 패널 복원

감독이 direction.yaml(숏 18·이벤트 84: marker 18·badge 18·article 11·photo 10·route 8·quote 6·panel 3·ships 3·clip 3·country 2·barrier 2)을 읽었다. 좌표 없는 지점·봉쇄선 삭제, versus 5:5, 실사 13, 휘장 0, 화면 라벨 0 — 좋다. 아래 둘은 **C0(이야기 안에 박힌 데이터 패널, 지도·시간축 한 세계)** 의 문제라 콘티 판 전에 고친다. hard 15건 수정과 같은 v3 로.

## 1. 시간축 패널 = act2 전체를 덮는 한 세계(D504 B안 · D-0450 §6)
- 지금: `panel timeline` 이 act2_0 → act2_1 끝(몇 초)과 act5_0 한 문장에만 있다. 이러면 휴전안 연표는 "잠깐 뜬 도표" 가 된다.
- 고칠 것: act2 패널은 **act2_0 시작 → act2_14(마지막 문장) 끝**까지 지속, **핀은 문장마다 at_word 로 차례로 등장**(9/24 → 9/26 → 9/30 → 10/6~8 → 10/11 → 10/25 → 10/28~30 → 10/31 → 11/3), 축 2026-09-15→11-15 고정. 패널 안의 카메라(핀 사이 이동)만 쓰고 지도 카메라는 멈춘다. 기사 카드·뱃지·quote 는 패널 위를 덮지 않는 자리(badge-over-panel 금지)로.
- act5 재진입: **act5_0 → act5_5** (조건부 시나리오 세 문장 + 하메네이 경고) 같은 축·같은 자리, 11/3 핀 강조. act5_6 부터 신호 목록으로 넘어간다.
- 중국 트랙 선례: 139초·344초 패널 두 번, 핀은 문장마다(D506).
