# 사진을 더 찾아 넣는다(UF-119) — 연출 v2 확정 전, 탐색 40분 상한

사용자 원문: "사진이 두장만 쓰이는거야? … 몇가지 더 추가해도 좋을거 같긴 해. 암튼 계속 진행해". 진행은 멈추지 않는다 — 연출을 쓰는 동안 병렬로 탐색하고, 찾은 것만 넣는다.

## 1. 탐색 대상(위키미디어 공용 `commons.wikimedia.org`·허용 호스트 안, 라이선스는 PD·CC0·CC BY 우선, CC BY-SA 는 저장소 권리 규칙이 허용할 때만 — `assets/rights_bundles.yaml` 기준, 아니면 제외)
| 장면 | 대상 | 후보 출처 |
|---|---|---|
| 콜드·1막 | 러시아 정유소(랴잔·키리시) 전경 또는 화재 | 공용 CC, 러시아 위키 사진가 CC BY |
| 2막 | 울산 정유단지(SK 울산 CLX)·울산항 유조선 부두 | 공용 CC BY(-SA), 한국 정부 공공누리 1유형(출처 표시) |
| 2막 | 블라디보스토크항·하바롭스크/콤소몰스크 정유소 | 공용 CC |
| 3막 | 외교부·청와대 브리핑(공식 사진, 공공누리) — 없으면 건물 외경 | 공공누리·공용 |
| 4막 | 라스라판 LNG(카타르), 하르그섬(NASA/USGS 위성, PD), 푸자이라항, 호르무즈 해협 유조선(미 해군 PD) | NASA·미 해군·공용 |
| 5막 | 백악관(이미 등재)·미 재무부 건물(PD, 미 정부) | 미 정부 PD |

## 2. 규칙
- 사실 장면의 AI 생성 금지(C0·G4-10), 모두 "자료사진" 표기 + 촬영 연월 + 출처 줄. 사건 당시 사진이 아니면 사건 장면처럼 쓰지 않는다(시설 전경은 "시설 소개" 문장에).
- 권리 기록(`rights_status`·license·author·url) 없이는 등재하지 않는다. 등재한 것은 **전부 배치**(D-0238 `[media-unused]`).
- 목표 5~8장(총 7~10장). 못 찾은 항목은 R 에 "없음(검색어·사유)". 프록시 403 으로 공용 접근이 막히면 즉시 R(question).
- 배치 밀도는 `media_beats`·`[cutaway-churn]` 안에서(사진 컷어웨이 사이 지도 복귀 ≥ shot_min_hold_sec).
