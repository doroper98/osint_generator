# 사용자 의견(UF-252) — 전형(대형)에 입체감, 각 군의 휘장, 병종(기병·창병·중무장보병·경무장보병) 이미지. 구상 컷 v2(2D relief + 3D 정지 컷) 로 반영해 다시 보인다

## 0. 사용자 원문(2026-11-01, 구상 컷 A·B 를 보고)
**"전형은 약간의 입체감이 있으면 좋겠는데? 그리고 긱 군의 휘장 같은게 있지 않아? 휘장이나 혹은 기병이면 기병 창병이면 창병 중무장보병 경무장보병 같은 이미지가 있으면 더 좋구"**
("긱 군" = 각 군으로 읽는다.)

## 1. 뜻(감독 해석)
- 지금 부대 블록은 2D 에서도 3D 에서도 **납작한 단색 면**이다. 사용자는 ① 대형에 두께·그림자 같은 입체감 ② 진영 휘장 ③ 병종을 한눈에 알리는 그림(픽토그램)을 원한다. 셋 다 부호 세트(`war_history.symbol_sets`)의 확장이고, 판정 ①·구상 컷 결정과 독립이다.
- 사용자가 제안한 순서(구상 컷 → 판정)가 살아 있으므로, 이 셋을 넣은 **구상 컷 v2**(칸나이 t=36.5, 2D relief 1장 + 3D 정지 컷 1장 + 8초 궤도)를 만들어 다시 보인다. 테마·3D 채택 결정은 그 뒤 사용자가 한 번에.

## 2. 지시 — 세 가지, 전부 규칙 키·레지스트리로(코드 상수 금지 P3)
### ① 입체감
- **2D(relief·dark 공통)**: 부대 블록에 두께 — 아래·오른쪽 단면(진영색을 어둡게 한 톤) + 바닥 그림자(알파·오프셋 규칙 값) + 위 모서리 밝은 선. 값은 `war_history.symbol_sets.depth`(감독 제안: 단면 두께 = 블록 높이의 0.12, 그림자 알파 0.35·오프셋 3px(480p), 모서리 선 알파 0.5). 회전한 블록(쐐기·사선)도 같은 규칙으로 단면이 따라 돈다.
- **대열 격자(선택, 권고)**: 블록 안에 대열을 뜻하는 작은 점·막대 격자(병력 수 비례 아님 — 수치 정직성, 블록당 고정 밀도 `rank_grid`). 보병은 가로 줄, 기병은 쐐기 방향 줄. 숫자를 암시하지 않는다는 주석을 규칙에.
- **3D(terrain3d)**: 블록을 높이 있는 박스(`unit_height_m` 규칙 값) + 윗면 밝게·옆면 어둡게 + 바닥 그림자. 대열 격자는 InstancedMesh 작은 기둥(결정적, 격자 밀도 규칙 값). 쐐기·점열 등 고대 부호 모양을 3D 에서도 같은 윤곽으로(R-0301 §3 "사각 면" 해소).

### ② 진영 휘장 — **지어내지 않는다**(D-0307 §3, C9). 사료·유물에 근거한 상징만
- 레코드: `assets/emblems/registry.json` 에 진영 휘장 항목 추가 — 로마: 군단 독수리(aquila) 도안(Commons PD/CC0 벡터, 또는 트라야누스 기둥·주화 사진에서 코드 재작도 — 출처·권리·"재현" 표기), 카르타고: 타니트 기호 또는 주화 도안(말 머리·종려나무 — 주화 레코드 `cannae_coin` 과 같은 출처 계열). 각 휘장에 `basis`(어느 유물·사료에서 왔는지 한 줄)와 `reconstruction: true` 를 두고, 화면 캡션에 "주화 도안 재현" 같은 라벨을 코드가 붙인다(period_art 라벨과 같은 장치).
- 현대(인천): 기존 `rights_check`·D5 그대로 — 유엔 휘장·미 해병대 휘장은 위키미디어 Restrictions(insignia·trademark) 가 있으면 쓰지 않고 국기로 대체, 사유 기록. 북한군 = 국기.
- 배치: 진영 범례(지금 색 네모) 옆에 휘장, 부대 블록 위에는 **작게**(픽토그램보다 작게, 가리지 않게). 값은 `war_history.faction_badge.emblem`.

### ③ 병종 픽토그램 — 코드 벡터 글리프 세트(권리 문제 없음, 한 스타일)
- 고대 병종 분류를 넓힌다: `symbol_sets.ancient.units` = `heavy_inf`(중무장보병)·`light_inf`(경무장보병)·`heavy_cav`(중기병)·`light_cav`(경기병)·`skirmisher`(투석·투창)·`elephant`. 근세·현대 세트는 그대로(현대 = APP-6).
- 글리프: `engine/glyphs/arms.py`(신규, cairo 경로) — 중보병 = 방패+투구 윤곽, 경보병 = 투창 든 사람 윤곽, 중기병 = 말+기수+창, 경기병 = 말+기수(투창), 투석병 = 투석끈, 코끼리 = 코끼리 윤곽. 단색(진영색 위 흰·검 halo), 크기 규칙 값(`symbol_sets.glyph.size_px` 480p 기준). 프리뷰 예제(세 곳 동시, P10): 갤러리 1장 `tools/element_gallery.py` 에 추가.
- 블록 위 배치: 픽토그램 + 라벨("아프리카 중무장보병"). 3D 에서는 빌보드.
- 칸나이 spec 의 부대를 새 분류로 다시 적는다(사료 귀속: 폴리비오스 III.113~114 — 리비아 보병 = heavy_inf, 히스파니아·켈트 보병 = heavy_inf(장비 차이는 라벨로), 누미디아 기병 = light_cav, 히스파니아·켈트 기병 = heavy_cav, 발레아레스 투석병 = skirmisher(있으면), 로마 군단 = heavy_inf, 벨리테스 = light_inf(있으면), 로마·동맹 기병 = heavy_cav). 분류 근거는 spec 주석에 출처 절.
