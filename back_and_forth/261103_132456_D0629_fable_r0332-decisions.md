# 결정 — R-0332: 음악 레벨 (가) 잠정, 효과음 겹치기 허용(조건), 슬로츠 카드는 사료 두 칸을 다 보이게 다시

## 1. 코리올란 음악 레벨 — (가) 잠정
- `audio.qa.music_under_narration_db_by_genre.war_history` 를 새로 둔다. 값은 **[−21.5, −9]** 이다. 아래 끝만 칸나이 실측(국소 감쇠 뒤 −20.78) 근처로 내린다. 위 끝은 공통 값(−9) 그대로 둔다. R-0332 예시의 [−22, −15] 는 쓰지 않는다. 위 끝을 −15 로 두면 전쟁사에서 평소 크기 음악(Zabriskie −12.47)이 막힌다.
- 명료도 하한 15 dB 는 hard 그대로다. 연출 국소 감쇠(clar/i1.yaml, 문장 12개)를 direction 에 옮긴다. 이유는 reason 에 적는다.
- (나) 목소리 대역 깎기는 하지 않는다. 사용자가 고른 곡의 음색을 바꾸기 때문이다.
- **잠정인 이유**: 사용자는 예전에 음악이 작다고 거절한 적이 있다("너무너무 작다", v2 −17.8 dB). 이번 값은 그보다 작다. 감독이 지금 사용자에게 이 맞바꿈을 알린다. 콘티 판 v2 청취 판정에서 작다고 하면 (다)·(라)를 사용자에게 묻는다. 규칙 주석에 "잠정 — 사용자 v2 청취 판정 대기(UF-256 후속)"를 적는다. 시험은 공통 범위 불변과 장르 키로만 갈림을 고정한다.

## 2. 효과음 — 실제 녹음 겹치기는 허용, 조건 넷
1. 같은 녹음의 여러 테이크와 여러 사본을 시간차를 두고 겹쳐 무리 소리(금속 난전·여러 마리 질주)를 만드는 것은 허용한다. 소리의 성질(걸음→질주, 한 번 부딪힘→다른 무기)은 바꾸지 않는다. 그래서 금지한 가공과 다르다.
2. 사본마다 음높이·속도 변화는 ±5% 이내로 둔다. 거리감 필터(고역 감쇠·잔향)는 D-0627 §2-2 그대로다.
3. 가공 내역을 권리 기록과 provenance 에 남긴다. 원천 파일, 겹친 수, 시간차, 음높이 범위다.
4. 라이선스 근거는 원천 사이트 자체의 약관 문구로 남긴다. BigSoundBank 는 사이트 라이선스 문구를 인용한다. 태그와 사이트 약관이 엇갈리면 뺀다(Pixabay 사례). Still North 는 원 사이트가 없으므로 OGA 라이선스 칸 + 작가 진술 인용을 남기고, 그 한계를 R 에 적는다.
- freesound 망 허용은 사용자 환경 설정이라 이번에는 요청하지 않는다. 있는 원천으로 견본을 만든다.

## 3. 지도 가림 수정(15cf1736) — 다시
- 슬로츠 카드가 손실 패널의 리비우스 칸을 덮는다. 이 패널은 논쟁 수치를 두 사료로 나란히 보이는 화면이다. 한쪽만 덮으면 같은 무게 원칙(C0)이 깨진다. 그 순간 자막이 폴리비오스 쪽이어도 마찬가지다.
- 고칠 것: 카드가 들어오면 패널을 왼쪽 절반으로 줄여 두 칸을 다 보이게 하거나, 카드를 패널 숫자·출처 줄과 겹치지 않는 자리에 둔다. map_cover_share 0 은 유지한다.
- **장치**: `card_over_panel` 이 사진 카드도 보게 넓힌다(hard). 지금 15cf1736 배치가 실패해야 한다. 같은 키를 모든 렌더 경로에 건다.
