## 쟁점 1. 수정 워커가 시각 정보를 못 본다 (17 §5.5 입력 목록)
- 실측: 이재명 뱃지가 타이틀 카드 밑에 남는다는 지적이 **3회 연속** 나왔다. 수정 LLM은 `end: scene_end open` 에서 −0.6, −1.6초씩 당겼다.
  그러나 타이틀 카드(20.3~25.9초)가 open 장면 **안**에 있어 그 앵커로는 고칠 수 없다. 맞는 답은 `end: {card: title}` 이다.
- 원인: 17 §5.5 입력은 direction·verdict·checks 뿐이다. 문장 시각표·카드 시각이 없다.
- **A (권고)**: 수정 입력에 연출가와 같은 문장 시각표(`plan_table`)와 카드 시각을 더한다. 17 §5.5에 주석 append.
- B: 문면대로 둔다. 시간 관련 지적은 사람이 게이트 ②에서 고친다.
- 근거: ② 17 §5.3 연출가는 같은 시각표를 받는다(같은 역할의 입력). ① 프롬프트 한 줄 — 되돌리기 쉬움. 15 P9 "자기 몫 입력"에 시각표는 수정 몫이다.

## 쟁점 2. 회차 사이 진동 (수정 LLM이 직전 회차만 본다)
- 실측: 1회차 지적 "clip:strikes 가 panel_gap 에서 타임라인을 가린다" → v2 에서 map_right_low 로 옮김(검수 v2 hard 0)
  → v3 에서 **다시 panel_gap 으로** 되돌림 → 검수 v3 hard 재발. 호르무즈 마커 라벨도 v3 에서 left 로 뒤집어 화면 왼쪽 끝에서 25px 잘림.
- **A (권고)**: 같은 루프 안의 앞선 changelog·판정 요약(회차별 지적 → 바꾼 것)을 수정 입력에 넣는다. "이미 되돌린 선택으로 돌아가지 말 것" 규칙 한 줄.
- B: 넣지 않는다(15 P9 "이전 버전 산출물을 참고로 넣지 않는다"를 엄격 해석).
- 근거: P9 의 금지 대상은 **이전 영상·옛 템플릿**이다(관성 전파). 같은 루프의 자기 이력은 관성이 아니라 진동 방지 입력이다. ① 되돌리기 쉬움.

## 쟁점 3. 상한 도달 시 어느 판을 게이트 ②에 올리나
- 현 구현: 마지막 판(v3). 실측에서는 v2 가 가장 좋았다(검수 hard 0, soft 5 vs v3 hard 2, soft 6).
- **A (권고)**: 상한 도달 시 (checks hard, 검수 hard, 검수 soft) 사전식 최소 판을 direction.yaml 로 되돌리고 provenance·qa_loop.md 에 "선택: v2 (사유)" 기록. 보관본은 모두 남긴다.
- B: 마지막 판 유지, 사람이 게이트 ②에서 판을 고른다(게이트 뷰에 판 목록).
- 근거: ② 17 §1 "코드가 루프를 제어" — 선택 기준도 코드가 정하는 편이 일관. ① 보관본이 있어 되돌리기 쉬움. 단 검수 LLM 판정 자체가 회차마다 흔들린다(같은 v1 을 세 번 본 판정이 9·10·8건) — 이 점에서 B 도 합리적.
