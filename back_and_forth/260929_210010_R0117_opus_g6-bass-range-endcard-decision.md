## 쟁점 1 — 저역 비율 범위 [−6, 0] dB 는 이 곡으로 도달할 수 없음

처리 전 값이 이미 +11.8 dB 입니다. 상승폭 조건(+4 dB 이상)을 지키는 한 결과는 [−6, 0] 에 들어갈 수 없습니다. 반대로 범위에 넣으려면 저역을 **깎아야** 합니다.

- **1-A (권고)**: 판정을 상승폭으로 바꿉니다. `audio.qa.bed_bass_rise_db: [4, 8]`(hard). 처리 후 절대 비율은 기록만 합니다(provenance·bed_stats).
  - 결과: hormuz +5.35, fed_policy +5.34 로 통과합니다. 곡이 바뀌어도 기준이 유효합니다.
  - 위험: 곡이 원래 저역이 약하면 절대 비율이 낮게 남을 수 있습니다. 상한 8 dB 로 과보강은 막습니다.
  - 되돌리기: 규칙 키 1개.
- **1-B**: 절대 범위를 이 곡 실측에 맞춥니다. `bed_bass_ratio_db: [14, 20]`.
  - 결과: 두 편 통과. 다른 곡(저역 약한 곡)은 처리 강도와 무관하게 실패할 수 있습니다.
- **1-C**: 대역 정의를 바꿉니다(예: 30–60 Hz 대 200–2000 Hz).
  - 이 곡 30–60 Hz 는 −23.8 dB 라 비율이 0 근처로 나옵니다. 숫자를 범위에 맞추려고 정의를 바꾸는 셈이라 권하지 않습니다.

## 쟁점 2 — "웅장함"의 실제 효과: 저역 절대 레벨은 거의 그대로

설계 A 는 처리 뒤에 피크 정규화를 합니다. 서브 층이 베드 피크를 약 1.9배 키웁니다. 그래서 정규화가 베드 전체를 약 5.7 dB 낮춥니다.
결과적으로 **저역 절대 레벨은 그대로(−13.62 → −13.97)이고 중역이 5.7 dB 내려갑니다.** 내레이션 대비로 보면 음악이 "더 묵직해진" 것이 아니라 "더 어두워진" 것에 가깝습니다. 청감은 사용자가 판정합니다.

저역 절대 레벨을 올리면(B) 음악 레벨이 −7.5 dB 가 되어 범위 [−15, −11] 를 벗어납니다. 이득을 절반으로 낮춘 B2 도 −10.3 dB 로 벗어나고 상승폭은 +2.5 dB 입니다.
bed_gain 0.47 은 못 바꾸고, 음악 레벨은 저역 에너지가 지배합니다. 그래서 **범위 [−15, −11] 안에서는 저역 절대 레벨을 약 +1.5 dB 이상 올릴 수 없습니다.**

- **2-A (권고)**: D-0097 설계 그대로(A). 합격표 조건을 모두 지킵니다(상승 +5.3, 음악 레벨 범위 안, 내레이션 변화 0). A/B 클립으로 사용자 청감 판정을 받습니다.
- **2-B**: 피크 정규화 기준을 처리 전 베드로 바꾸고(B), music_under_narration 범위를 새 값으로 개정합니다(v3 합격 수치 변경 = README §7.2, 골든 회귀 필요).
- **2-C**: A 에 더해 중역 손실을 줄이는 중간안입니다. 정규화 기준 = 처리 전·후 피크의 기하평균입니다. 저역 약 +2.8 dB, 중역 약 −2.8 dB 로 예상합니다(실측 전). 음악 레벨이 범위 상한 −11 근처에 닿을 수 있습니다.

## 쟁점 3 — fed_policy 엔딩 카드: 음악 크레딧을 넣으면 넘침

  - 되돌리기: credits.yaml 한 블록. D-0099 A(절 합치기·열 재배치)와 같은 종류입니다.
