- UF-250(2026-11-01, 참고 그림 3장 — 1917 가자·베르셰바 쇼츠): "혹시 전장에 대한 설명을 할때 이런 상세한 지형 사진이 그려진 지도를 쓸 수 있나? 그리고 전형을 설명할땐 3차원 공간 상에서 드론으로 천천히 회전하며 찍는 듯한 그런 형태로 구성하면 좋을거 같은데 가능해?"
- UF-251(감독 제안 순서 — "칸나이 전술 무대를 밝은 릴리프로 1프레임, 3D 궤도 정지 컷 1프레임을 실제 렌더로 먼저 → 두 컷을 보고 전쟁사 기본 테마와 3D 무대 채택 결정"에 대한 답): **"응 니가 정한 순서대로 가"**

## 1. 범위 — 구상 컷 둘, 실제 렌더(목업 금지), 칸나이 전술 무대 기준. 판정 ① 대기와 병행한다(D-0603 의 "판정 전 v2 렌더 금지" 는 그대로이나, 이 두 컷은 사용자가 지시한 별개 구상이라 예외)
### A. 밝은 릴리프 지형 1프레임(먼저)
- 새 지도 테마 `rules geo.themes.relief`(값 = 감독 제안, R 에 전후 컷): 모래색 고도 계단(`land_stops` 저지 밝은 모래 → 고지 갈색), `land_shade` 대비를 dark·light 보다 높게(음영이 지형을 읽게), 바다 짙은 청, 와디·강 선은 가늘고 밝은 선. 글자·라벨은 현 light 테마 할로 규칙 그대로(읽힘 우선, UF-02·D-0329~0333 검사 전부 적용).
- **수계**: 기존 NE 강은 큰 강만이라 참고 그림 같은 잔가지가 없다. `tools/dem_drainage.py`(신규): Terrarium 고도에서 흐름 누적을 계산해 임계 이상 셀을 선(geojson, 프로젝트 폴더·미추적)으로 뽑는다. 임계·단순화 값은 규칙 키(`geo.themes.relief.drainage`). 출처 고지 = 고도 타일 출처(지금 geo.prep 가 쓰는 것) 그대로 RIGHTS·엔딩 자료 줄.
- **축척 막대**: 참고 그림의 축척 막대는 느낌으로 가져온다 — 코드 조판, 왼쪽 아래, 규칙 키(`sketch.war.scale_bar` 또는 본편 `hud` 아래 — 모서리 요소가 아니라 지도 안 요소로. 모서리는 날짜 뱃지만, C0). 값은 카메라 축척에서 계산(출처 없는 숫자 아님).
- 컷: 칸나이 v1 spec 그대로 t=36.5(포위 완성) 1프레임 + 같은 시각 현 dark 컷을 나란히 둔 비교 1장. 부대·강·지명·전선 변경 없음.
### B. 3D 궤도 정지 컷 1프레임(+ 판정 보조 8초 궤도 mp4, 선택)
- proposed 무대 `terrain3d`(레지스트리 `stages_planned` 에 추가 — 등록 전이라 스케치 경로 `sketch/war` 에서만 호출, P10).
- 구현 경로: **headless Chromium + three.js**(컨테이너 playwright 기설치, three.js 는 npm 고정 버전·MIT·라이선스 기록) 를 기본으로 한다. numpy 2.5D 가 더 낫다고 보면 R 에 근거와 함께 권고(결정은 감독). 렌더는 결정적(고정 시드·고정 조명·고정 카메라 곡선)이어야 한다 — 골든 가능.
- 장면: Terrarium 고도 → 높이맵 메시(고도 과장 배수는 규칙 키), 텍스처 = A 의 릴리프 음영 이미지(같은 세계, 같은 색), 부대 블록 = 지형 위에 얹은 납작한 면(시대 부호 세트 색·모양 그대로), 전선·화살표 = 지형 위 띠, 지명 핀·라벨 = 빌보드(화면 글자 크기 규칙 그대로).
- 카메라: 전장 중심을 축으로 고도각·궤도 반경·각속도는 규칙 키 `terrain3d.camera`(감독 제안: 고도각 40°, 반경 = 전장 폭 ×1.6, 한 바퀴 ≥ 60초 — 느리고 끊김 없이, 문장 앵커에 묶는다. 문장마다 튀는 줌·급회전 금지 C0). 정지 컷은 궤도 중 한 방위(남서에서 북동을 보는 꼴 등 — 양익 포위가 보이게) 1프레임, 보조로 8초 궤도 mp4.
- 화면 요소: 모서리는 날짜 뱃지만. 시각(예: 16시 30분)은 부대 라벨이나 날짜 뱃지 안에(큰 시각 뱃지 금지). 지휘관 초상 메달리온은 기존 person 프리미티브 + 권리 레코드로(지어내지 않음, 추정 표기).
- **금지**: 참고 그림 조판 이식(모서리 섹션 제목·브랜드 바·큰 시각 뱃지 — 이미 뺀 것, C0), 사실 장면 AI 생성, 출처 없는 수치.
