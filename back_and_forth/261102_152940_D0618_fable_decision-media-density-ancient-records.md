# 결정 — R-0324 media_density: (가)를 좁혀서. 고대·근세 전쟁사는 **사료 인용 카드(quote.source)를 "기록"으로 센다**, 데이터·증거 패널은 세지 않는다. 칸나이 직결 후대 작품 1점 더

## 1. 근거(사용자 원문 둘을 함께)
- UF-139 원문: "그래프만 주구장창 보여줄꺼면 … 레퍼런스 사진이나 영상 풍부하게 하란 말은 어디다 팔아먹고" — 그래프·패널 대신 **레퍼런스 자료**를 보이라는 뜻.
- UF-206 원문: "과거 전쟁은 미술과 기록, 현대 전쟁은 사진과 영상과 기록을 적극적으로" — 사진이 없는 시대의 레퍼런스 = 미술 + **기록**.
- 그래서 고대·근세에서 **사료 인용 카드(원문·저자·권·장이 있는 기록)** 는 레퍼런스 자료로 센다. 패널(사상자 띠·증거 패널 등 데이터 그림)은 UF-139 가 말한 "그래프" 쪽이라 세지 않는다. 하한 값(분당 1.5)은 낮추지 않는다((나) 기각 — 사용자 장치 약화). 관계 약한 유물로 채우기((다))는 UF-201 교훈(주된 피사체가 문장과 맞아야)에 어긋나 기각.

## 2. 규칙(감독 결정, 되돌릴 수 있음)
- `media.density.count_kinds_by_genre.war_history.{ancient, early_modern}`: [photo, clip, period_art, document, quote_source]. modern 은 지금 그대로(photo·clip·document).
- quote_source 가 셈에서 차지하는 몫 ≤ 1/3(규칙 키 `quote_source_max_share: 0.34`) — 기록 카드로만 채우는 것을 막는다.
- 검사 메시지·provenance 에 종류별 셈을 남긴다. 시험: 패널은 세지 않음, 몫 상한 초과 = 실패, modern 은 quote 를 세지 않음.

## 3. 칸나이
- 지금 사진 카드 7 + 사료 인용 2 = 9. 한 점 더 — **칸나이와 직접 이어지는 후대 작품**을 찾는다. 후보: 세바스티앵 슬로츠 「칸나이에서 죽은 로마 기사들의 반지를 세는 한니발」(1704, 루브르 대리석상 — Commons 의 Jastrow 촬영본은 보통 PD-self, 실제 틀 확인). 붙일 자리는 전투 뒤 패배 규모 문장(aftermath 사상자 쌍). 캡션은 작품 사실만(작가·연대·소장처·후대 묘사 라벨) — 반지 일화 자체를 사실로 서술하지 않는다(원고에 없는 내용이므로, 캡션 둘째 줄은 "리비우스 XXIII.12 의 일화를 조각한 작품" 정도로 출처를 밝힌 범위만).
- 권리 통과 사진이 없으면 다른 칸나이 직결 후대 작품(아이밀리우스 파울루스의 죽음을 그린 다른 판화·회화 등)으로, 그것도 없으면 decision_request.
- 사용자에게는 콘티 판 전달 때 "고대 편은 사료 인용 카드도 레퍼런스로 셌다"를 한 줄로 알린다(감독).
