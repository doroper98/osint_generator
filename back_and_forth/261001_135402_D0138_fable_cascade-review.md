# 겹침 카드(cascade) 콘티 시트(fe765ae) — Fable 검수: 방향 맞음, 보강 3건 뒤 사용자 판정

사용자 재구성(띠 폐기 → 겹침 카드)은 **사용자 결정 D116** 으로 기록한다. D-0135 설계·D-0136 보강은 대체됐다. **D-0137 은 유효**하다(지명 깔림 A, 문장 지명 hard / 배경 지명 warning, 새 카드 지연 규칙, 골든 25/25 = 승격 조건) — cascade 에 그대로 적용한다.

## 확인
- 지금 사건이 앞·크게(214×82·accent 윗선), 지난 사건은 뒤로 물러나 겹친다. 폭 486(최악 554 ≤ 560). 깊이감은 띠보다 분명히 낫다. 모서리 날짜 무접촉, checks hard 0, 테스트 7.
- 트럼프(파랑)·카타르(청록) accent 가 당사자 전환을 읽게 한다. 좋다.

## 보강(사용자 판정 전, 렌더 없이)
1. **뒤 카드 몸통이 빈 판처럼 보인다**(③~⑦). 날짜 아래가 비어 "불 꺼진 탭" 네 장이 늘어선다. 고친다: 뒤 카드도 **제목을 그대로 둔다** — 앞 카드가 자연히 덮는다(창 겹침 문법). 덮이는 경계에서 글자가 반 토막 나지 않게 **보이는 폭 끝 12 px 를 알파 그라데이션으로 흐린다**(`back_fade_px`, 규칙 키). 이건 자름이 아니라 가림이다(제목은 그 사건이 앞에 있을 때 이미 온전히 보였다). 부제·윗선은 지금처럼 물러나며 사라진다.
2. **깊이를 더 준다**: 뒤로 갈수록 `back_dy`(규칙 키, 예 +5 px/층) 아래로 내려앉고 바탕을 층마다 조금 더 어둡게(`back_dim`, 예 0.06/층). 평면에 겹친 판이 아니라 뒤로 물러난 창으로 읽히게.
3. **전환 중 글자 겹침(②)**: 물러나는 카드의 제목·부제를 `focus_sec` **앞 절반**에 먼저 지우고, 새 카드 글자는 **뒤 절반**에 띄운다(띠 v2 판단 ③과 같은 순서). 두 글자가 같은 자리에서 비치는 프레임 0 을 테스트로 단언.
