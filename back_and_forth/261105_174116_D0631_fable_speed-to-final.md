# 지시 — 완성본 단축(UF-264 "빨리 내놔 완성본"). 게이트 순서는 지키고, 승인 전 준비를 미리 끝낸다

## 0. 사용자 원문
- UF-264: "빨리 내놔 완성본"

## 1. 지키는 것
- 게이트 ② 는 사용자 "승인" 뒤에만 전편 렌더(state RENDER)로 간다. 엔진 CLI 를 직접 불러 승인 전에 전편을 뽑는 것도 하지 않는다(게이트 장치 우회 금지).

## 2. 줄이는 것
1. **승인 전에 끝낼 준비**: 720p 3D 프레임 미리 그리기(terrain3d_prep, 2배 그리기 포함), 고해상도 지도 원천 내려받기·캐시, 효과음·코리올란 편집 믹스. 승인 뒤에는 전편 렌더와 전달 인코딩만 남게 한다.
2. **프리뷰 자료는 가볍게**: 게이트 ② 자료는 프리뷰 시트(대표 프레임) + 전후 비교 프레임 + mix 수치 + 렌더 전 검사 hard 0 이다. 프리뷰 영상 전편은 만들지 않아도 된다(규칙이 요구하면 그대로).
3. **지도 해상도 시간 상한 60분**: 고해상도 원천이 60분 안에 안 되면 바로 보고한다. 그때 대안은 카메라 확대를 원천 해상도 안으로 제한하는 것이다. 대안으로 가도 basemap_upscale 은 통과해야 하고, 확대 구간의 연출 변화는 R 에 적는다.
4. **단독 커밋 미루기**: basemap_upscale 전파용 단독 커밋은 칸나이 완성본 전달 뒤에 낸다(최종 감독에게 감독이 알린다). 지금은 65672e40 에 들어 있다.
5. **한 시간마다 push**: 끝난 단위는 바로 push 한다. 컨테이너 재시작이 잦다(worker_epoch 9).

## 3. 다음
- 프리뷰 자료가 준비되면 artifacts `preview_v1/` + R. 감독이 실물 확인 뒤 사용자에게 게이트 ② 를 요청한다.
- 승인 뒤: 전편 720p → QA → final_deliver(≤30MB) + srt·credits·provenance → artifacts `final_v1/` + R.
