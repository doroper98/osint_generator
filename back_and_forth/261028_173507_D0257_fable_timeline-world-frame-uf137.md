# 지시 — 시간축 세계를 화면 가득 채우지 않는다(사용자 의견 UF-137) · 콘티 판 v2

사용자 원문(2026-10-28, econ 콘티 판 v1 시청): **"금리 차트가 화면 좌우에 다 꽉차서 만드는 UI는 UX 측면에서 최악인거 같아."**
원장 UF-137(open, 장치는 이 D 의 ③ — 콘티 판 v2 전에 단다).

## 1. 진단(감독 실측, 콘티 판 v1 프레임)
- 시간축 무대(timeline)의 레인 선이 x=0 에서 화면 오른쪽 끝까지 이어지고, 레인 제목·출처 줄은 왼쪽 가장자리에, 축 값(5.5%·0%)은 오른쪽 가장자리에 붙어 있다. 위아래도 자막 바로 위까지 레인이 차지한다.
- 지도 무대는 화면을 채워도 "세계"로 읽히지만, 선·글자·눈금이 가장자리에 닿는 차트는 대시보드로 읽힌다. 기준 영상(diesel v2)의 데이터 패널은 모두 여백을 가진 상자 안에 있었다.
- 원칙은 유지한다: **하나의 연속 세계**(D-0251 §6.1). 바뀌는 것은 그 세계를 **화면 안쪽 안전 영역의 틀 안에 담는 것**이다. 세계는 틀보다 넓을 수 있고(카메라가 그 안을 이동), 틀 밖으로는 그리지 않는다(클립).

## 2. 할 일(한 커밋 한 의도)
① **시간축 무대 틀(frame)** — `rules stage_timeline` 에 틀 키 신설(이름·값은 decision_request 로 제안: 좌우 여백, 위 여백(날짜 뱃지·카드 자리 아래), 아래 여백(자막 위), 레인 제목 열 폭, 축 값 열 폭, 모서리·테두리·바탕 알파). 레인 선·계단·띠·핀·눈금은 틀 안에서만 그린다(틀 밖 클립). 레인 제목·출처 줄은 틀 안 왼쪽 열, 축 값은 틀 안 오른쪽 열. 세로 비율은 "레인 3개 + 사건 레인" 이 틀 안에 들어가도록 `lane_h` 를 틀 높이에서 역산(값은 무대가 정한다 — 사용자 값 아님). **비네팅은 쓰지 않는다**(C0 되돌리면 안 되는 것·`hud.forbidden_components`).
   - 디자인 px 는 480p 기준으로 제안하고, 지도 무대 골든(diesel·hormuz)에는 영향이 없어야 한다(25/25).
② **차트 아일랜드(backdrop 무대)와 같은 틀 문법** — island.chart 의 레인 영역 수치(`rules island.chart`)와 같은 패딩 체계를 쓴다(두 경로가 다른 수치를 갖지 않게, C12-3 "한 트랙만 보호 = 미보호"). A 연출(direction.A.yaml)도 같은 틀로 그려진다.
③ **장치 `[chart-edge-bleed]` hard** — timeline 무대·차트 아일랜드에서 레인 선·레인 제목·축 값·출처 줄·눈금 글자의 상자가 안전 영역(틀) 밖에 닿으면 실패. 콘티 판·프리뷰·전편·스케치 같은 키. 원장 UF-137 guards 에 check·rule·test 를 달고 status guarded.
④ **콘티 판 v2** — ①~③ + D-0256 ①(끝값 라벨·출처 줄 겹침) 반영 뒤 `render --animatic` 다시 → artifacts/showcase-v7.4.0 showcase_econ/animatic.mp4 교체(md5 갱신, 이전 본은 `animatic_v1.mp4` 로 남긴다) → R + send_message. 사용자 흐름 검토는 v2 로 다시 받는다.
⑤ 수치 결정 전에 골격(틀 클립·열 배치)을 만들고, 값은 decision_request 한 번에 묶어 올려라(§6.4-3). 결정 전에 값을 규칙 파일에 넣지 않는다.

## 3. 하지 않는 것
- 레인을 줄여서 해결하지 않는다(세계는 그대로, 틀만). 차트를 여러 아일랜드로 쪼개지 않는다(§6.1).
- geo 쇼케이스(지도 무대)는 이 지시의 대상이 아니다 — 다만 geo 의 dual_line·dots 패널은 이미 상자 안이다(확인만).
