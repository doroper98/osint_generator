# 경로 라벨 시인성(D-0191 §1-3·D-0192) — 골든 영향 2건(결정 요청)

## 1. 한 일(작업 트리, 미커밋)
| 항목 | 내용 |
|---|---|
| 자리 고르기 | `engine.layers.routes.place_route_label` 한 함수(렌더·검사 공용). 후보 0 = 옛 자리(가운데 점 위 11px), 그 뒤 곡선 위 `place_fracs` 7곳 × 선의 양쪽 수직(위쪽 먼저), 선에서 `line_gap` 5px. 통과 = 어떤 경로 선도 상자를 안 지나감 + 장애물과 안 겹침 + 화면 안 |
| 장애물 | 그 프레임 예약 상자(뱃지·마커 라벨·겹침 카드) + 마커 부제까지 글자 상자 + 해역 이름 + 그 순간 자막 줄 + 먼저 놓인 경로 라벨 |
| 그리기 순서 | 경로 라벨을 마커·뱃지 뒤로 미룸(`flush_route_labels`) — 장애물을 알고 고르기 위해. 그린 상자는 `R.reserved` 로 → 배경 나라·도시 이름이 피한다 |
| light 모양 | 테마 `route_label{style: ink, halo 3.4, mark 12×3, gap 5}`: 짙은 글자(테마 글자 톤) + 밝은 halo, 경로 색은 글자 앞 짧은 막대. dark 는 `route_label` 없음 = 경로 색 글자(종전) |
| 대비 | 경로 라벨을 `contrast="required"` 로 — `[map-contrast]` 측정·v5.21.2 국소 보정과 같은 판정 시점 |
| 검사(hard) | `route_label_cross`: 경로 선 ↔ 경로 이름표, 경로 선 ↔ 마커 라벨·부제 글자 줄 상자. `route_label_overlap`: 이름표가 어느 후보로도 장애물을 못 피함(해역 이름·뱃지·마커·다른 이름표·화면 밖). 라벨 ↔ 뱃지는 기존 `label_collision` 이 새 자리로 잰다(D-0199 §3) |

증거: `docs/handoff/reports/phaseD0191/golden_p0059_route_label.jpg`(전·후, dark·light).
- **권고: 두 기준선의 이 컷 md5 갱신**(superseded 기록). 사용자 지적과 같은 결함을 고치는 변화.
