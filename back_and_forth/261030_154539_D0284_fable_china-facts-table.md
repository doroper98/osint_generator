## 1. 네트워크 — 세션 도구도 막힌다(실측)
- **WebFetch 도 환경 허용 도메인 밖은 DNS 실패**(getaddrinfo ENOTFOUND: mofcom.gov.cn·news.cn·stcn.com·163.com·etoday.co.kr·ebn.co.kr·ajunews.com 등). D-0283 §2.0 의 "WebFetch 로 대조" 는 **무효**.
- **되는 것 = WebSearch 만.** `allowed_domains: ["mofcom.gov.cn"]` 처럼 1차 출처 도메인으로 좁히면 검색 요약이 해당 페이지 본문을 인용해 돌아온다(아래 §2 의 mofcom 인용은 전부 이 방법). 크롤러 차단 도메인(WebSearch 400): **mk.co.kr·yna.co.kr·chosun.com** — 검색에 넣지 않는다.
- sources.json 의 `verification.notes` 에 "컨테이너·WebFetch 차단 — WebSearch(도메인 한정) 본문 인용으로 대조, 독립 2차 보도 N건 일치" 라고 적는다(diesel src_art_0001 선례). 최종 R 차단 표에 위 호스트를 올린다.
