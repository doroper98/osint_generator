# SK-G2 — 검토본 포위망 두 개가 미세 자기 교차(shapely invalid)

## 쟁점

D-0145 §2 는 SK-G2 = "shapely valid · 면적 > 0(hard)" 이고, §0 은 "검토본 그대로, 결함 수정 없음" 입니다.
검토본 레시피(4d9dc65 `pocket_1123`·`pocket_1130` 을 그대로 데이터화)를 그대로 넣으면 **두 포위망 모두 invalid** 입니다.
그래서 두 지침이 충돌합니다.

## 실측

| 포위망 | 꼭짓점 | 면적(deg²) | explain_validity | make_valid 결과 |
|---|---|---|---|---|
| 11.23 | 473 | 0.3912 | Self-intersection (44.6692, 48.9183) | MultiPolygon [0.39124, **0.00001**] |
| 11.30 | 255 | 0.1946 | 같은 점 | MultiPolygon [0.19465, **0.00001**] |

- 원인: 레시피의 스탈린그라드 시가 두 점 `[44.61, 48.79] → [44.67, 48.92]` 와 그다음 북쪽 개시선 첫 점 `(44.6746, 48.9167)` 이 맞물리는 곳에 **나비 모양 조각(1e-5 deg² ≈ 0.1 km²)** 이 생깁니다.
- 화면 크기: 마지막 숏(w 2.3°, 480p) 기준 약 **2 px²**. 보이지 않습니다. 비교 시트 7컷은 이 레시피로 **픽셀 동일**(0.000 %)입니다.

## 선택지

**A. 검사에 미세 조각 허용치(권고)**
- 새 규칙 키 `checks.pocket_sliver_ratio`(예: 1e-3). `make_valid` 결과의 가장 큰 조각을 뺀 나머지 면적 / 전체 ≤ 비율이면 통과하고 **warning 으로 기록**(조각 수·면적·위치), 넘으면 hard. 자기 교차가 크면(진짜 결함) 여전히 hard.
- 검토본 화면 그대로(픽셀 동일 유지). 음성 테스트(큰 자기 교차 레시피)는 그대로 hard.
- 되돌리기: 키 하나.

**B. 레시피 데이터 수정**
- 시가 두 번째 점을 빼거나 옮겨 교차를 없앤다. valid 엄격 유지.
- 화면이 아주 조금 달라진다(포위망 동쪽 끝 모양 · 비교 시트에서 0이 아닌 비율). D-0145 §0 "결함 수정 없음" 과 충돌.

**C. SK-G2 를 '면적 > 0 + make_valid 뒤 다각형 수 1' 로 재정의**
- A 와 비슷하나 허용치가 없다(0.00001 조각도 실패) → 검토본 실패. 불채택 권고.

## Opus 권고

**A**, 값 1e-3. 판정 기준 ①(키 하나) ②(D-0145 §0 검토본 그대로) ③(실측 — 조각은 전체의 0.003 %).
조각 위치는 run_log "후보" 에 적어 본편 등록 때 레시피를 다듬을 수 있게 합니다.
