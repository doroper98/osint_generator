# 결정 요청 — 추정 태그(prov_tag) 위치: 08 §9 우상단 vs C0 "모서리에는 날짜만"

## 쟁점
08 §9는 번들 차트의 추정 태그를 **패널 우상단 (W−40, 52)** 에 둔다(v2 `prov_tag`).
그런데 CLAUDE.md C0·`rules hud.allowed_corner_elements: [date_badge]` 는 모서리에 날짜만 허용한다. 날짜 배지(`hud.date_badge`: x_right 26, y 40, 밑줄 y 48)는 패널이 떠 있어도 그려진다(`engine/hud.draw_date` 는 패널 위, 풀카드 때만 숨김). 그래서 (W−40, 52) 태그는 날짜 배지와 같은 자리에서 겹친다.
태그 자체는 빼면 안 된다(08 §9 "번들 기반 차트는 반드시 표시", G4).

## 선택지
**A. 08 §9 그대로 우상단(W−40, 52)**
- 결과: v2 모양 그대로. 날짜 배지와 겹친다(모서리 요소 2개).
- 위험: C0 "되돌리면 안 되는 것 — 모서리 요소" 위반 소지. 사용자 지적 3(모서리 규칙)과 충돌.
- 되돌리기: rules 좌표 한 줄.

**B. 패널 제목 아래 가운데(부제 줄 다음, y ≈ 116)**
- 결과: 모서리 규칙 준수. 제목과 붙어 "이 차트는 추정" 이 먼저 읽힌다.
- 위험: 부제가 있는 패널은 제목·부제·태그 세 줄이 되어 본문 시작(y ≈ 118~135)과 가깝다. 차트별 본문 y 를 10px 내릴 수 있음.
- 되돌리기: rules 좌표 한 줄.

**C. 차트 본문 영역 오른쪽 위(모서리가 아닌 본문 안, 예: x = 본문 오른쪽 끝, y = 본문 위 끝)**
- 결과: 모서리 규칙 준수, 제목 영역 무변경. 차트마다 본문 경계가 달라 위치가 조금씩 다르다.
- 위험: 차트 요소와 겹칠 수 있어 차트별 값이 필요.

## Opus 권고: B
- ③ 저장소 규칙(C0·rules hud)이 핸드오프 문서(08 §9) 좌표와 충돌 → 저장소 규칙 우선 + 기록.
- ① 셋 다 rules 한 줄로 되돌린다. B 는 차트마다 따로 값을 두지 않아 가장 단순하다.
- ② 08 §2 "제목은 중앙 상단" 과 한 묶음으로 읽혀 v3 문법과 맞는다.

## 막히는 범위
- 막힘: `prov_tag` 좌표 값 하나. 결정 전에는 **08 §9 값(A)으로 구현**해 둔다(권고안 선반영이 아니라 핸드오프 명세값). 결정이 오면 rules 한 줄을 바꾼다.
- 계속함: 작업 5의 차트 6종 모델·렌더러·예시·프리뷰, 작업 6·7.
