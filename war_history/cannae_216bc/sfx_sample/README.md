# 칸나이 — 전투 효과음 견본 둘 (v7.4.0, UF-258)

같은 화면(콘티 판 v2 178~218초, 3D 접전 — 기병 충돌·하마 백병전·중앙 보병 압박·양익 포위·동맹 기병 패주)에 소리만 다르다.

- sfx_sample_no_sfx.mp4 — 내레이션 + 코리올란(콘티 판 v2 와 같은 믹스).
- sfx_sample_sfx.mp4 — 위 + 녹음 효과음 층 6큐(먼 거리감): 기병 질주·하마 백병전 금속음·말 울음 1회(178.5~191초), 중앙 보병 군중·금속음(201~216초), 동맹 기병 질주(211~216초).
- 두 판 모두 엔진과 같은 2패스 loudnorm(전편 믹스 기준) 뒤 잘랐다(sfx_sample_loudnorm.json, −14.02 LUFS). 효과음 층은 믹스 대비 약 −22 dB(차이 RMS) — 멀리서 들리는 바탕.
- 명료도(효과음 포함 믹스): 전편 최저 15.60 dB, 견본 구간 최저 16.48 dB(encirclement_0). 처음 값(기병 구간 질주 0.6·금속 0.45·울음 0.5)은 encirclement_1 14.59 dB 로 15 아래라 0.45·0.3·0.35 로 낮췄다.
- sfx_log.json — 가공 내역(원천 id·테이크 위치·사본 시간차·음높이 범위 0.95~1.05·울음 구간). 겹치기 조건 D-0629 §2.
- direction_sample.yaml — 견본 전용 연출(본 연출에는 큐 없음).
- sfx_registry.yaml — 원천·권리(녹음 14: Still North CC0 금속 7 · BigSoundBank CC0 질주 4 · radio aporee PDM 군중 1 · Commons PD 울음 1 · Briefer 외 CC BY 4.0 울음 1).
- 크레딧(이 견본에 쓰인 CC BY): 말 울음 녹음: Briefer E. et al.(2015) Scientific Reports 5:9989, doi:10.1038/srep09989 · CC BY 4.0 · 변경: 거리감 필터·잔향·음높이 ±5 %.
- 권리에 맞는 녹음이 없던 것: 여러 마리 기병 질주(한 마리 녹음 4개를 시간차로 겹침), 실제 집단 난전 금속음(단발 녹음 55개를 겹침).
