## 이 스케치에서 드러난 것(T3 에서 다룬다)
- 0 기준 막대는 데이터(13.6~16.5)가 레인 위쪽 15 % 에 몰린다 → `[axis-empty-band]`(아래 68 %)·`[flat-lane]` 이 hard. 막대 레인은 0 이 정직성 기준이므로 `[bars-from-zero]` 와 함께 이 둘의 막대 레인 예외가 필요하다.
- 막대 높이 차이가 작게 보인다(0 기준이라 정상). 차이는 act1 의 예상치 표식·차이 라벨(estimate)이 말한다 — 다음 스케치.
- `[plot-height]`·`[chart-only-run]`·`[media-density]` 는 영상 문법 검사 — 실적 템플릿은 사진 배경 + 차트 아일랜드(D-0304)라 본편에서 채운다. 스케치는 요소만 본다.
