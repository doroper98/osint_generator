# T2 bullet(예상 대 실제) 스케치 (D-0308 §1-1 · D-0315 ②)

- 예상 = 속빈 막대(윤곽 2px, 바깥 끝 3px) — 자라지 않고 먼저 떠 있다. 실제 = 채움, 최신만 accent
- 실제가 있는 열: 값 라벨 위 한 줄 "예상 0.4 · +30%"(차이 % 코드 계산). 실제가 없는 열(4분기): "예상 0.43"
- 범례 없음. princess 팔레트, 축척 w 636 한 벌
