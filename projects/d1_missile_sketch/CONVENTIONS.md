# Phase D1 표현 규약 — 미사일 발사·탐지 자산·해양 경계 (2026-10-05)

북한 미사일 발사 영상을 만들 때 그대로 꺼내 쓰는 규약이다. 사용자가 스케치 영상을 보고 합의한 결과다.
아직 엔진 레지스트리에 등록하지 않았다(스케치 단계). 코드는 이 폴더의 `sketch_d1.py`(2D)와 `globe3d.py`(3D)다.

## 1. 다시 만드는 방법

```bash
pip install -r requirements-engine.txt          # + 시스템 폰트 fonts-noto-cjk
python tools/fetch_data.py fonts
python -m geo.prep projects/d1_missile_sketch && python -m geo.prep projects/d1_missile_sketch --res 720p
python -m geo.prep projects/d1_missile_sketch/globe_tex          # 3D 지구본 텍스처(전 지구, ppd 8)
# EEZ 원본(Marine Regions WFS, CC BY 4.0)을 받아 eez.json 생성
curl -o /tmp/eez.json "https://geo.vliz.be/geoserver/MarineRegions/wfs?service=WFS&version=1.0.0&request=GetFeature&typeName=MarineRegions:eez&outputFormat=application/json&bbox=115,25,150,48"
python projects/d1_missile_sketch/prep_eez.py /tmp/eez.json
python projects/d1_missile_sketch/sketch_d1.py   # → out/d1_sketch.mp4
python projects/d1_missile_sketch/globe3d.py     # → out/d1_globe_proto.mp4
```

새 발사 사건에는 `sketch_d1.py` 맨 위 "사실 값"(발사 지점·착탄 기준점·거리·비행 시간·정점 고도)과 `SOURCES`만 바꾼다.

## 2. 사실 표기

| 항목 | 규약 |
|---|---|
| 발사 지점 | 발표 표현 그대로("평양 순안 일대"). 발사 기호(삼각형)와 시각 |
| 착탄 지점 | 점이 아니라 **불확실성 영역**(발표가 "약 ○km"이면 반경 원). 발표 기준점(예: 오시마오시마)까지 거리선을 함께 그림 |
| 비행 거리 | **발표값만** 화면에 쓴다. 근사 좌표로 계산한 거리를 보이지 않는다(980km 대 발표 1,000km 사고) |
| 두 기관 수치 | 합참·일본 방위성을 **나란히 같은 무게**로(고도 단면 패널) |
| 궤적 | 2D 지도에는 지상 투영(대원)만. 고도는 단면 패널 또는 3D. 곡선 모양은 "개념", 정점 고도는 발표값 |
| 미사일 이미지 | 권리가 분명한 도해 우선. 방송 화면 캡처는 라이선스가 의심되면 쓰지 않음 |

## 3. 탐지 자산

| 경우 | 표현 |
|---|---|
| 위치 공개(성주·샤리키·교가미사키) | 기준점 + 부채꼴 테두리 선명. 거리 = 공개 사양 |
| 위치 비공개(그린파인) | **기준점을 찍지 않음**. 여러 겹 흐림 + "위치 비공개 · 범위는 개념도" 태그 |
| 이동 자산(이지스함) | "함정 위치는 예시 · 탐지 거리 비공개", 범위 그리지 않음 |
| 3D 방위·고각 | 공개 정밀 사양 없음 → "(개념)" 표기 |
| 가시 판정 | 사양·궤적 모양에 좌우되는 "탐지 시각"은 쓰지 않는다(지어낸 정밀도). **레이더 수평선 최소 고도** = R(1/cos(d/R) − 1)만 쓴다(거리·지구 반지름 기하) |

## 4. 해양 경계(EEZ)

| 경우 | 표현 |
|---|---|
| 확정·단독 EEZ | 나라 색 옅은 채움 + **바다 쪽 경계만** 점선(해안선 쪽 선은 그리지 않음) |
| 중첩 주장(독도·쿠릴 등) | **두 나라 색이 번갈아 드는 사선** — 한쪽 색으로 칠하지 않는다 |
| 공동 관리(한일 공동개발구역) | 초록(합의 색) 점무늬 |
| 독도 문구 | "독도 주변 수역 · 일본이 영유권 주장 · 대한민국 실효 지배" (문구 최종 확정은 사용자) |
| **서해 남북** | Marine Regions 남북 계산선은 **쓰지 않는다**(NLL도 북한 주장선도 아님, 북한 EEZ가 NLL 남쪽까지 내려옴). **NLL(금색 실선)과 북한 1999 해상군사분계선(붉은 점선) 사이를 남북 두 색 빗금**으로. 북한선 3점 이후는 "방향 미발표" 점선·태그 |
| NLL 좌표 | 현재 **개략 재구성**(서해 5도와 북측 해안 중간점 원칙) — 화면에 "개략". **본편 전 공식 좌표(국방부 자료·해도)로 교체 필수** |
| 동해 남북 | 아직 계산선 그대로 — 서해와 같은 방식으로 정리할 과제 |

## 5. 카메라·3D

- 숏 전환 이동은 **앞 숏이 끝난 상태(푸시인 포함)에서 시작**한다. 원래 값에서 다시 시작하면 첫 프레임 줌이 튄다(멈칫 사고).
- 큰 줌(4배 안팎)은 2.4초 이상.
- 2D → 3D: 접점 기준 반지름 kR 구(거리·방위 보존)로 k를 80 → 1로 줄여 평면을 지구본으로 휜다. 궤적은 실제 축척(정점 6,000km ≈ 지구 반지름).
- 남은 과제: 실제 축척 옆 시점에서 레이더 볼륨이 작아 보임 → 근접 숏 추가. 엔진 정식 무대(globe) 등록.
